## Установить

Скачайте готовый бинарный файл из [GitHub Releases](https://github.com/0xcd21h/borg-commander/releases) или запустите установщик для macOS или Linux. Поддерживаются Intel и ARM:

```sh
curl -fsSL https://raw.githubusercontent.com/0xcd21h/borg-commander/main/scripts/install.sh | sh
```

Установщик проверяет контрольную сумму архива и помещает `borg` в каталог из PATH, чтобы программа запускалась в том же терминале. Если `~/.local/bin` уже входит в PATH, используется он; если `/usr/local/bin` доступен для записи, например под root в контейнере, используется этот каталог; иначе выбирается `~/.local/bin` и добавляется в файл запуска оболочки. После установки запускается Borg. `BORG_NO_RUN=1` пропускает запуск, а `BORG_INSTALL_DIR` позволяет указать каталог. Если та же версия уже установлена, повторный запуск пропускает скачивание. Для сборки из исходного кода нужен Rust 1.97 или новее:

```sh
cargo install --locked --git https://github.com/0xcd21h/borg-commander borg-app
```

Поддержка Homebrew подготовлена. После публикации tap-репозитория:

```sh
brew install 0xcd21h/tap/borg-commander
```

Запустите `borg` в папке, которую хотите открыть. F10 — выход; Ctrl-O возвращает из консоли к панелям. Для обновления скачанной программы выполните `borg update`; если установка выполнена через Homebrew или cargo, используйте соответствующий менеджер пакетов. `borg --version` показывает установленную версию.

## Темы и значки

Выберите тему с помощью F9 → Параметры → Тема. См. [галерея тем](../../../README.md#themes) для Midnight, Aurora, Neon, Classic, Paper и Ember.

В темах используются фиксированные цвета, поэтому настройки палитры терминала не меняют их внешний вид. Терминалы без truecolor используют ближайшие цвета из палитры 256-colour.

Значки файлов отображаются всегда. Ghostty автоматически использует более богатые значки Nerd Font. Другие терминалы по умолчанию используют переносимые символы: `/` для папок, `@` для ссылок и `*` для исполняемых файлов. Установить `icon-style = "nerd"` использовать насыщенные значки в другом терминале с подходящим шрифтом или `icon-style = "portable"` заставить переносимые символы. По умолчанию, `"auto"`, адаптируется к терминалу, не сохраняя это обнаружение в качестве предпочтения шрифта.

Архивы релизов включают в себя **Borg Mono**, моноширинный шрифт со значками Nerd Font. Установите обычные и жирные шрифты из `fonts/`, выберите Borg Mono в терминале и выберите `"nerd"` стиль значка. Borg не может изменить шрифт вашего терминала. Установщик сохраняет их в `${XDG_DATA_HOME:-~/.local/share}/borg-commander/fonts`; Homebrew удерживает их внутри `$(brew --prefix)/share/borg-commander/fonts`.

## Коллекции и рекурсивный поиск

Меню «Поиск» открывает коллекции и осуществляет рекурсивный поиск по имени файла. Оба используют сортируемые результаты с исходными путями, существующую программу просмотра и быстрый предварительный просмотр.

- **Ctrl-F:** рекурсивный поиск в текущей папке и ниже. Должны совпасть все слова: `main rs` находит `main.rs`, а `a | b` — любое из двух. Слово в нижнем регистре не учитывает регистр; слово с заглавной буквой учитывает его точно. Также работают шаблоны вроде `*.log`, фразы в кавычках, пути с косой чертой, например `src/lib`, и `-word`, чтобы исключить совпадения, а также фильтры `ext:rs,toml`, `type:file`, `type:dir`, `type:link`, `size:>10M`, `size:1M..50M`, `mod:<7d` (изменено за последнюю неделю), `mod:>1y` и `in:src` (папка в любом месте пути). Ctrl-P и Ctrl-N в поле запроса возвращают прежние поиски, сначала сделанные в той же папке.
- **Alt-K:** собрать отмеченные файлы или текущий файл на другой панели. Добавление ссылки не копирует содержимое файла.
- **Alt-V:** выберите сохраненную коллекцию из прокручиваемого списка с количеством записей и оценками размера. Нажмите F7 или N, чтобы создать его. Коллекции сохраняются при перезапуске Borg.
- **Esc:** скрыть результаты, сохранив курсор, прокрутку, метки, фильтр и группировку.
- **Alt-Shift-R:** возобновить скрытый просмотр. Сканирование продолжается, пока оно скрыто.
- **Alt-D — Размеры папок:** находите папки по их общему размеру или количеству файлов, включая скрытые файлы по умолчанию. Откроется диалоговое окно Ctrl-F, установленное на *Итоги по папкам*; переключение   *Ищите* перемещается между ними. Ctrl-C останавливает сканирование.
- **Alt-S:** рассчитать размеры выбранной папки. **Alt-Shift-D:** открыть дерево размеров для текущей папки.
- **Alt-W:** развернуть или восстановить активную панель результатов. По умолчанию результаты открываются на обычной панели. Строка заголовка `[+]` (максимизировать), `[=]` (восстановить) и `[-]` (свернуть) элементы управления кликабельны. Свернуть скрывает вид; Alt-Shift-R возобновляет его с сохранением макета и выбора.
- **Ctrl-S:** фильтровать результаты по имени или исходному пути. Пустой фильтр показывает все.

Щелкните заголовок столбца, чтобы отсортировать его или обратить вспять. Меню «Влево/Вправо» также предлагают сортировку; Поиск добавляет сортировку и группировку исходных папок по папкам или типам файлов. Enter в заголовке группы сворачивает его; Вставка отмечает соответствующие элементы. Метки выдерживают сортировку и фильтрацию; нижний колонтитул также учитывает отмеченные файлы, скрытые фильтром.

F3 и Ctrl-Q открывают настоящий исходный код. F5 копии в реальное место назначения; если целевая панель представляет собой коллекцию, вместо этого добавляются ссылки. F6 требует реального пункта назначения. F8 удаляет ссылки из коллекции. В результатах поиска F8 просит удалить оригиналы. Shift-F8 также удаляет оригиналы из коллекции после подтверждения. Если отмечены и папка, и ее содержимое, папка отправляется в задание один раз. При показе оригинала открывается исходная папка на другой панели. Влево или Esc скрывает результаты; Alt-Shift-R возобновляет их на том же месте. Tab переключает виртуальные панели, даже если в оболочке есть ожидающая команда. Оболочка сохраняет настоящий рабочий каталог. F10 всегда спрашивает, прежде чем уйти.

Поиск считывает имена файлов и метаданные с возможностью отмены рабочего процесса и максимум 20 000 совпадений на каждый поиск. Контекстная строка показывает завершение, ошибки, пропущенные записи и был ли достигнут этот предел. Скрытые папки следуют за пунктом «Показать скрытые файлы». Поиск остается в начальной файловой системе и не повторяется по символическим ссылкам каталога. Окно поиска может ограничить результаты файлами или папками и установить минимальный размер. Выберите **Итоги по папкам** для измерения всех файлов-потомков перед фильтрацией по имени, размеру или минимальному количеству файлов. Он хранит 20 000 крупнейших папок и сортирует содержимое по размеру; вместо этого нажмите «Файлы», чтобы ранжировать их по количеству файлов. Используйте такой шаблон, как `node_modules` или `*cache*`, или `*` чтобы проверить все, что находится под выбранным корнем. Итоговые значения учитывают содержимое файла, а не гарантированное восстанавливаемое дисковое пространство. Строки вложенных папок перекрываются. Символические ссылки никогда не выполняются, сканирование остается в начальной файловой системе, а папка, содержащая самого себя (через привязку или папку с жесткой связью), вводится только один раз; такие границы, а также нечитаемые или исключенные дочерние элементы делают итоговые суммы неполными, что показано знаком ≥. Сканирование каталогов использует метаданные и не считывает содержимое файлов. Результаты появляются после измерения; сканирование остается подлежащим отмене. **Дерево размеров папок** показывает корневую папку и ее подпапки на текущей панели. Вправо расширяет ветку или входит в расширенную ветку; Влево сворачивает его или выбирает его родителя. Enter открывает настоящую папку. Нажмите стрелку ветки, чтобы свернуть или развернуть, или заголовок столбца, чтобы отсортировать одноуровневые элементы по имени, размеру или количеству файлов. Esc скрывает дерево; Alt-Shift-R восстанавливает свои ветки, метки и курсор. Файловые операции используют реальные пути, а пометка родительского и дочернего элементов отправляет только родительский объект на задание копирования или удаления.

Поиск по именам пропускает сгенерированные папки, пока отмечен флажок **Пропускать результаты сборки, кэши и игнорируемые файлы**: `node_modules`, `.git`, кэши и виртуальные окружения Python, папки вроде `target` и `dist`, если рядом лежит файл сборки (`Cargo.toml`, `package.json`), и любые папки с файлом `CACHEDIR.TAG`. Пропускаются и файлы, исключённые через `.gitignore`, `.ignore`, `.rgignore` или `.borgignore`, а также шаблоны из `[search] exclude`. Пропущенная папка, имя которой само совпадает с запросом, всё равно появляется в результатах, а строка контекста показывает, сколько папок пропущено. `excluded:yes` один раз ищет везде, а `hidden:yes` включает скрытые файлы. Подсчёт размеров всегда читает всё. История поиска хранится на этом компьютере и доступна только вам; `history = false` в разделе `[search]` отключает её.

**Поиск → Индексировать эту папку для мгновенного поиска** хранит индекс всех имён в активной папке и ниже, поэтому Ctrl-F в ней или в любой вложенной папке отвечает сразу; строка контекста показывает, когда построен индекс. Индексы перестраиваются в фоне после запуска Borg и когда им больше 15 минут, а прежний индекс отвечает, пока новый не готов. Поиск, который ничего не пропускает или использует другие исключения, обходит папки. Выберите пункт ещё раз, чтобы прекратить индексирование и удалить индекс. Индексы хранятся в папке кэша вместе с подсчётами размеров; `[index]` в конфигурации перечисляет индексируемые папки.

Чтобы измерить размеры, оставив обычные панели файлов открытыми, нажмите **Alt-I** или выберите **Поиск → Подсчет размеров в фоновом режиме**. Borg сканирует каждую папку под текущим каталогом, включает скрытые файлы и заполняет общие сведения о папках по мере их завершения. Вы можете перемещаться по консоли или использовать ее во время ее работы. В папках, которые все еще измеряются, наблюдается растущее общее количество отмеченных `≥`, и итоговые значения сохраняются, когда вы выходите из папки и возвращаетесь. Нижний колонтитул панели показывает прогресс; **Alt-I** снова или щелчок по нижнему колонтитулу останавливает сканирование и сохраняет измеренные итоговые значения. Запуск задания копирования, перемещения или удаления останавливает текущее сканирование по размеру. Завершенные сканирования используют общий кэш с деревом размеров и анализом пространства.

Завершенные сканы сохраняются локально. И анализ пространства, и дерево папок повторно используют сохраненное сканирование для одной и той же политики корневых файлов и скрытых файлов. Повторное открытие измеренного корня немедленно использует этот снимок: `~` отмечает кэшированные размеры с датой измерения над деревом. **Ctrl-R** повторное сканирование в любом размере; **Ctrl-C** отменяет. Предыдущее дерево остается видимым во время обновления и сохраняется после отмены или сбоя. В обычных списках папок также отображаются доступные кэшированные итоги. Изменения за пределами Borg могут сделать их устаревшими; навигация не запускает рекурсивное сканирование. Borg задания копирования, перемещения и удаления делают недействительными снимки, которые перекрывают измененные пути.

Локальный индекс SQLite сохраняет каждую измеренную папку, имеющую до 16 корней. Деревья нагружают детей по мере расширения ветвей; ветка отображает до 20 000 папок, а анализ плоского пространства сохраняет самые большие 20 000 совпадений. Эти пределы отображения не останавливают сканирование и не уменьшают измеренные итоговые значения. В строке «Файлы в этой папке» учитываются байты, хранящиеся непосредственно в расширенной папке. Ошибки и пропущенные поддеревья помечают итоги как неполные. Файлы кэша живут в `~/.cache/borg-commander`, уважая `XDG_CACHE_HOME`; `BORG_CACHE_DIR` переопределяет местоположение. Это одноразовые измерения, отдельные от коллекций. Файлы с жесткой связью учитываются один раз для каждого пути. Это логические размеры содержимого, а не использование физического или восстанавливаемого диска.

Действия Git и архивирования в настоящее время работают из реальных панелей каталогов. Используйте Reveal original для доступа к собранному файлу.

## Клавиши

Двухстрочная панель быстрого доступа расположена под командной строкой. Функциональные клавиши находятся в первом ряду; поиск, коллекции и другие контекстные ярлыки находятся на втором. Обе строки кликабельны. Уведомления временно заменяют вторую строку.

| Ключ | Действие |
| --- | --- |
| Вверх, Вниз, PgUp, PgDn, Домой, Конец | Переместить |
| Enter, Верно | Открыть папку/запустить или просмотреть файл |
| Левый | Перейти в родительскую папку |
| Tab | Переключить панель или перейти к быстрому просмотру/вернуться к списку файлов. |
| Ctrl-O | Показать оболочку/обратно к панелям |
| Alt-I | Подсчитайте размеры папок в фоновом режиме/остановите подсчет |
| Ctrl-S | Быстрый поиск в папке |
| Ctrl-Q | Быстрый просмотр: на другой панели просматривается файл под курсором (текст, изображение или папка). |
| Ctrl-L | Информация: на другой панели отображается размер, режим, владелец, даты и свободное место. |
| Вставить, Ctrl-T, Shift-Up/Вниз | Отметить файлы |
| `+` `-` `*` | Выделить, отменить выделение или инвертировать по шаблону (`*.rs`, `build/`) |
| Alt-Enter | Поместите отмеченные имена (или текущее) в командную строку |
| Ctrl-Insert / Alt-Shift-Insert | Скопировать отмеченные имена / их полные пути |
| Shift-Enter, Ctrl-J | Вставьте новую строку в курсор командной строки; Enter запускает команду, Ctrl-C очищает ее |
| Alt-A / Alt-Shift-A | Поместите путь к папке этой панели/другой панели в командной строке. |
| Shift-PgUp / Shift-PgDn | Прокрутка истории вывода консоли |
| Shift-Home / Shift-End | Самый старый вывод консоли / возврат к интерактивной подсказке |
| Ctrl-P / Ctrl-N, Ctrl-R | История оболочки: предыдущая/следующая команда, поиск (осуществляется вашей оболочкой) |
| Альт-. | Показать скрытые файлы |
| Alt-Shift-Left/Верно | Изменение размера панелей |
| Ctrl-U | Поменять панели |
| Alt-J | Задания: приостановить или отменить выполняемое копирование, перемещение и удаление. |
| Alt-M | Монитор активности: процессы и память |
| Alt-C | Docker: Создание проектов и контейнеров. |
| F1 | О |
| F2 | Меню «Файл» |
| F3 | Просмотр (текст или изображение) |
| F4 / Shift-F4 | Редактировать во встроенном редакторе / в `$VISUAL` или `$EDITOR` |
| F5 / F6 | Копировать/переместить на другую панель |
| F7 | Создать папку |
| F8 | Удалить |
| F9 | Строка меню |
| F10 | Выйти |

Tab, Enter, Home, End, Left и Right действуют на панелях, пока командная строка пуста. Когда вы вводите команду, эти ключи попадают в оболочку. Ctrl-P, Ctrl-N и Ctrl-R используют историю команд вашей оболочки. Shift-Enter (или Ctrl-J) вставляет новую строку без запуска команды. Введенные и вызванные многострочные команды расширяют одну и ту же область подсказок, уменьшая панели и оставляя курсор видимым. В оболочке сохраняются обычные клавиши редактирования и завершения.

Копии попадают в буфер обмена вашего компьютера через терминал, в том числе по SSH и в зеркале, которым вы управляете. Borg также хранит последние 20 копий: Ctrl-V или Shift-Insert вставляет последнюю в собственные поля Borg, например в диалоги и поиск по памяти, даже там, где терминал не может обратиться к вашему буферу обмена. В командной строке Ctrl-V остаётся клавишей оболочки, поэтому вставляйте туда клавишей вставки вашего терминала. Меню «Файл» предлагает оба вида копирования для клавиатур без Insert; копии, слишком большие для терминала, остаются в Borg.

Если ваш терминал зарезервировал F-клавиши, нажмите **Esc, затем цифра** в течение 1,5 секунд: Esc 1–9 — это F1–F9; Esc 0 — это F10. Например, Esc 9 открывает меню, а Esc 5 копирует. Пока Borg ожидает цифру, в строке функциональных клавиш отображаются цифры, которые нужно нажать. Esc сначала закрывает то, что открыто (уведомление, результаты, быстрый просмотр или информация); секунда Esc отменяется. Alt-1–0 также работает, когда Alt достигает терминала. В macOS при необходимости включите Option as Meta в вашем терминале.

## Мышь и консоль

Щелкните строку, чтобы сфокусировать ее, дважды щелкните ее, чтобы открыть, и щелкните правой кнопкой мыши, чтобы отметить ее. Нажмите на строку меню или нижние действия, чтобы использовать их. Колесо перемещается по записям панели.

Ctrl-O переключает между панелями и консолью. Оболочка следует за папкой активной панели, прежде чем вы вводите или открываете консоль. В zsh он автоматически меняет папку и перерисовывает подсказку; в bash и fish короткометражка `cd` Вместо этого команда появляется в консоли. Команды и Ctrl-C сохраняют видимость явно открытой консоли. «Возврат в панели после команды» применяется к командам, запускаемым с панелей. В командной строке Option/Alt-Left и Option/Alt-Right перемещаются по словам.

В консоли колесо прокручивает историю вывода, не меняя набираемую команду. Shift-PgUp/PgDn прокрутить страницу; Shift-Home переходит к самому старому выходу; Shift-End возвращается к прямой трансляции. Ввод также возвращается к интерактивной подсказке. Используйте жест выбора вашего терминала, обычно Shift-drag, а затем обычный ярлык копирования, чтобы скопировать видимый вывод.

## Плагин Git

Git — это встроенный плагин, включенный по умолчанию. F9 → Параметры → Плагины открывает соответствующий флажок; его отключение скрывает меню Git и столбцы состояния, а также останавливает фоновое сканирование статуса. Для этого требуется Git на вашем PATH.

Внутри репозитория на панелях отображается ветка и двухсимвольный статус рядом с каждым файлом. Левый символ описывает индекс (поэтапные изменения); справа описано рабочее дерево. `M` означает модифицированный, `A` добавил, `D` удалено, `R` переименован, `??` неотслеживаемый, и `U` конфликт. В папках суммируются изменения, находящиеся под ними. Чистые и игнорируемые файлы не имеют маркера. За пределами репозиториев имена файлов используют дополнительное пространство.

Меню Git предлагает статус репозитория, неподготовленные и проиндексированные различия, последние коммиты и этапы/отмены для отмеченных файлов (или текущего файла, если ничего не отмечено). Диффы и история открываются в обычном просмотрщике. Unstage сохраняет рабочие файлы. Статус обновляется после навигации, команд и действий Git, а также каждые пять секунд, пока панели неактивны. Статус обновления в меню Git немедленно пересканируется.

## Docker плагин

**Alt-C** или **Команда → Docker** отображает ваши контейнеры на активной панели, сгруппированные по проектам Compose, при этом контейнеры вне Compose отображаются последними. На другой панели отображается выбранный контейнер: его состояние, порты, сети, монтирование, команды и политика перезапуска, с живым CPU, использованием памяти, сети и диска, а также графиком за последнюю минуту. В проекте отображается папка проекта, его контейнеры и их совместное использование. Esc закрывает вид.

| Ключ | Действие |

Остановка и перезапуск сначала спросите. В проекте действие затрагивает только те контейнеры, которые оно изменяет, поэтому «Пуск» запускает остановленные.

**F** в работающем контейнере закрывает представление Docker и показывает файловую систему контейнера на этой панели, начиная с его рабочего каталога. Заголовок панели называет контейнер. Другая панель сохраняет свою папку хоста, поэтому **F5** копирует в любом случае, и **F3** просмотры, **F7** создает папку и **F8** удаляет внутри контейнера. Поиск, размеры, предварительный просмотр и редактирование остаются на хосте. **Alt-C** возвращается к виду Docker; `..` в корне контейнера возвращает панель в папку хоста, которую она показывала ранее. Просмотр потребностей `sh` в контейнере, поэтому минимальные изображения без оболочки не могут быть перечислены.

В файлах контейнера командная строка следует за панелью: она становится оболочкой этого контейнера, запускаемой в папке панели, с именем контейнера в начале приглашения. Команды выполняются внутри контейнера, панель обновляется после их завершения, а `cd` там перемещается панель. Ctrl-O показывает консоль этого контейнера, отмеченную **▣ консоль имени**; на панели хоста командная строка и Ctrl-O снова принадлежат хосту, и все, что вы там набрали, сохраняется. Оболочка контейнера такая же, как и вкладка «Оболочка» в представлении Docker.

Выключить **Docker — командная строка следует за панелями контейнеров** в «Параметры» → «Плагины», чтобы сохранить командную строку на хосте. Под файлами контейнера он затемняется и помечается **⌂ хозяин**, и Enter ничего не запускается, пока хост-панель не активна, поэтому команда никогда не запускается не на том компьютере.

**E** открывает оболочку в контейнере (bash, если она есть в изображении, в противном случае `sh`) на вкладке «Оболочка» панели сведений и отправляет туда ваши ключи, включая функциональные клавиши. **Alt-1** показывает обзор и **Alt-C** возвращается в список; колесо мыши прокручивает историю. Оболочка продолжает работать, пока вы просматриваете другие контейнеры, закрываете представление Docker или используете консоль хоста, а ее контейнер помечен `›_` в списке и рассчитывается по ярлыку Alt-C. Он закрывается, когда вы выходите из него, когда его контейнер останавливается или когда Borg завершает работу, которая запрашивает сначала, когда оболочки открыты. Плагин использует `docker` CLI и его текущий контекст, поэтому он работает как с Docker Desktop, OrbStack, Colima, так и с удаленными движками. Его можно отключить в «Параметры» → «Плагины».

## Claude и другие агенты (MCP)

`borg mcp` позволяет агенту ИИ, такому как Claude, работать в открытом у вас borg, на вашем компьютере или на сервере, к которому вы подключаетесь через SSH. Кроме borg ничего устанавливать не нужно: агент запускается `borg mcp` сам, через SSH для сервера, и подключается к открытому там сеансу borg. Серверу не нужен ни открытый порт, ни доступ в Интернет.

С именованными рабочими пространствами `borg sessions list` показывает их идентификаторы и имена; `borg sessions create NAME` добавляет один, и `borg --session NAME` открывает его. `borg mcp` могу позвонить `list_sessions`,
`list_remote_sessions`и `use_session` чтобы выбрать цель для этого соединения MCP. Вызов инструмента также может предоставить `session` Идентификатор для переопределения одним вызовом. Выбранная цель остается частной для этого соединения MCP.

`borg service install`, `enable`и `start` настроить дополнительную фоновую службу. Он владеет парным соединением машины и поддерживает работу именованных сеансов, когда их терминалы отсоединяются. `borg service attach NAME` снова подключается к одному. Ctrl-] отделяется, не заканчивая свою оболочку. Использование `borg service stop`, `disable`, или `uninstall` контролировать жизненный цикл услуги. В контейнере без systemd запустите супервизор процессов контейнера. `borg service run`; тот `install` и `enable` для команд требуется хост systemd на Linux.

После сопряжения `borg --remote MACHINE:SESSION` открывает файловую систему этого сеанса на левой локальной панели. Enter или F3 позволяет предварительно просмотреть удаленный файл посредством временной локальной загрузки. **F5** копирует отмеченные файлы и папки между локальной и удаленной панелями или между двумя парными хостами. Диалоговое окно назначения идентифицирует клиента или хост. Копии выполняются как фоновые задания с побайтным прогрессом, паузой/отменой, а также перезаписью, пропуском или сохранением обоих вариантов. Папки включают пустые папки и символические ссылки; разрешения на выполнение и время модификации сохраняются для обычных файлов. Файл становится видимым в конечном пункте назначения только после того, как его содержимое полностью доставлено. Перемещение (F6) и удаление (F8) в удалённых панелях недоступны. Правая панель останется на вашем компьютере. С **Параметры → Плагины → Следовать** включена, командная строка и **Ctrl-O** используйте интерактивную оболочку на удаленном хосте. Его терминал отображается локально; клавиши, вставка, Ctrl-C и терминальные программы запускаются удаленно. Каждый удалённый сеанс сохраняет свою оболочку и незавершённую командную строку, пока вы переключаете панели. Выбор клиентской панели восстанавливает локальную оболочку. Приложения, использующие альтернативный экран, и приложения на переднем плане, использующие необработанный ввод, например `top`, получите все ключи во время работы, включая Ctrl-O. Изменение размера терминала достигает удаленного PTY. Выйдите из приложения, используя его собственные клавиши (`q` в `top`); Borg возвращает в панели, если вы запустили его из командной строки панели, или оставляет удаленную консоль открытой, если вы запустили ее там. Собственные панели и оболочка удалённый клиента Borg не зависят от этой консоли. Использование `borg get MACHINE/SESSION:PATH [TO]` и `borg put FROM MACHINE/SESSION:PATH` для передачи файлов. В местном Borg нажмите **Alt-R**, используйте нижнюю часть **Удаленные хосты** ярлык или выберите **F9 → Удаленный → Просмотр хостов и сеансов…** чтобы увидеть спаренные машины и их именованные сеансы. Enter открывает файлы выбранного сеанса на панели, которая открыла средство выбора, заменяя предыдущее местоположение этой панели. Нажмите **M** в окне выбора, чтобы открыть зеркало экрана; **R** обновляет список. **Tab** переключается между **Хозяева** (исходящий доступ) и **Клиенты** (входящий доступ). Клиенты перечисляет компьютеры, сопряженные с этим Borg, их отпечатки открытых ключей, сведения о том, подключены ли они, и количество их подключений. Один компьютер появляется один раз, даже если зеркало использует несколько подключений. Статус обновляется, пока средство выбора открыто, в том числе внутри сеанса, соединения которого принадлежат фоновой службе. Сопряжение является направленным: разрешенный клиент не становится автоматически хостом, файлы которого этот Borg может просматривать. Если владелец соединения не может сообщить их состояние, сопряжённые клиенты остаются в списке с отметкой **Статус подключения недоступен**. При подключении зеркала средство выбора отображает анимированный статус и **Esc** отменяется немедленно. На каждый шаг подключения отводится 10 секунд, на всю попытку — не более 30 секунд. После неудачной попытки окно выбора остаётся открытым и показывает, какой шаг не удался; **M** повторяет попытку для выбранного сеанса. В сборщике **F2** переименовывает выбранную метку хоста для каждого сеанса на этом хосте; **Shift-F2** переименовывает выбранную метку сеанса. Эти метки сохраняются в этом клиенте и отображаются в средстве выбора, заголовках панелей и нижнем колонтитуле консоли. Оставьте имя пустым, чтобы восстановить оригинал. В деталях сохраняются исходные имена хоста и сеанса. Метки привязаны к ключу парного хоста и идентификатору сеанса; цели и имена команд на удаленном хосте остаются прежними.

**F8** на недоступном хосте удаляет его сопряжение на этом клиенте. **Shift-F8** удаляет выбранный хост, даже если он в сети. По умолчанию в подтверждении выбрано **Нет**. При этом закрываются панели и консоли этого клиента для данного хоста; сеансы и файлы на хосте сохраняются. Идентификатор клиента и его остальные сопряжения не меняются. Чтобы подключиться снова, выполните сопряжение заново.

**F8** или **Удалить** удаляет выбранный сеанс хоста после подтверждения, по умолчанию **Нет**. Удаление закрывает этот сеанс и его удаленные консоли, а также удаляет сохраненные панели Borg и историю терминала; файлы и папки на хосте сохраняются. Сеанс по умолчанию защищен. Автономный сеанс, в котором в данный момент находится соединение, не может удалить себя; закройте его на хосте и сначала запустите Borg в другом сеансе. В случае неудачного удаления сеанс остается видимым для повторной попытки. Сеансы, управляемые службой, останавливаются до удаления сохраненного состояния, и служба не создает их заново.

Средство выбора отличает исходящие хосты от входящих клиентов; один и тот же Borg может выполнять обе роли. Меню Remote также предлагает **Хост, установленный на зеркале** и **Поделитесь этим Borg как организатор…**. Средство выбора показывает версию Borg каждого хоста; при выборе сеанса отображается ОС/архитектура, фоновая служба или режим терминала, задержка запроса и адрес ретрансляции. Хосты проверяются одновременно, поэтому недоступный хост не скрывает результаты от других. Хост, который не может сообщить свою версию, показывает **версия недоступна**; версия реле не является версией хоста. Обновляйте Borg на обоих компьютерах: хост без нужной удалённой функции показывает сообщение о необходимости обновления.

Удалённые папки загружаются частями, с индикатором загрузки и счётчиком полученных записей; переход в другое место отменяет запрос. `borg mirror MACHINE:SESSION` показывает живой экран удаленного сеанса на вашем локальном терминале; Alt+Shift+M открывает то же зеркало с локального Borg с удаленной панели. **Ctrl-G** покидает зеркало и возвращается к локальным панелям: удерживайте Control и нажмите G. Также можно нажать на нижнюю строку баннера. Зеркало отображает свой статус управления в строке выше; Ctrl-] также выходит. `--take` явно берет управление от другого зрителя. Регулярный `borg` или `borg --session NAME` можно зеркально отображать во время работы; фоновая служба не требуется. Его локальный терминал остается видимым, а ввод с локальной клавиатуры или мыши возвращает управление зеркалу. Зеркало соответствует макету хост-терминала и обрезается так, чтобы соответствовать меньшему размеру клиентского окна; увеличение клиента показывает все остальное. Дополнительный фоновый хост поддерживает сеансы после закрытия их исходного терминала и позволяет управляющему клиенту изменять размер своего PTY. Если удаленный сеанс контролируется другим терминалом, зеркало открывается в режиме только для просмотра; его ключи не меняют удаленный сеанс. Нажмите **Ctrl-T** или щелкните строку состояния, чтобы взять на себя управление, отсоединить другой терминал или использовать `borg mirror MACHINE:SESSION --take` взять на себя управление при запуске. Взяв управление на себя, первая клавиша пробуждает спящий удаленный экран; последующие клавиши и ввод мыши достигают его. Отстающий зритель получает текущий экран вместо старых кадров анимации. Ввод `exit` в основной оболочке Borg (Bash, Zsh или Fish) запрашивает подтверждение. **Нет** выбран по умолчанию и сохраняет ту же оболочку, переменные, каталог и зеркала. В удалённой консоли `exit` спрашивает, закрыть ли оболочку на хосте; после «Да» выберите сеанс снова через Alt-R, чтобы открыть новую.

Чтобы подключиться, нажмите F1, а затем C (или F9 → Удаленный → Поделиться этим Borg как хостом…). Borg показывает две команды, которые нужно вставить в терминал на вашем компьютере: одна запускает Claude Code, уже подключенный к этому borg, другая сохраняет соединение в Claude Code для каждого сеанса. Tab выбирает один, Enter копирует его в буфер обмена вашего компьютера через терминал, который работает через SSH в iTerm2, Ghostty, kitty, WezTerm и Alacritty (в tmux, с `set -g set-clipboard on`). Там, где терминал ее не принимает, как во многих браузерных терминалах, F3 показывает только команду в виде обычного текста, при этом мышь свободна для ее выбора; любая клавиша возвращается к borg. По SSH borg заполняет адрес, по которому вы вошли; Если ваш компьютер подключается к серверу по другому имени, например, по псевдониму SSH или через переходный хост, введите вместо этого это имя. SSH необходимо войти в систему без запроса пароля: ключа или агента SSH. `borg mcp setup prod` печатает то же самое для Claude Code и Claude Desktop из командной строки.

Подключившись, агент видит то, что видите вы: сам экран в виде текста, находитесь ли вы в панелях или в консоли, обе панели, выделенные и отмеченные файлы, где идет командная строка и что там набирается. Он называет места как местоположения: абсолютный путь или `~/…` на машине borg работает, `docker://web/etc/nginx` внутри контейнера или путь относительно активной панели. Не спрашивая, он считывает папки, файлы (по диапазонам строк или строк, содержащих текст), самые загруженные процессы и контейнеры и показывает файл или папку на другой панели.

Все, что меняет машину, ждет вас в диалоговом окне, в котором показано все это: команда и место ее запуска, новый файл или редактирование в виде разницы. Длинные прокручиваются с помощью клавиш со стрелками, PgUp и PgDn или колесика мыши, а F3 отображает диалоговое окно в полноэкранном режиме. «Нет» выбрано до тех пор, пока вы не выберете «Да»; в редактировании отказано, если файл изменился, пока вы принимали решение. Для сопряженного компьютера: `approval_mode` спрашивает один раз, прежде чем включить «Утвердить все для этого сеанса». Его значок остается видимым; щелкните значок или нажмите Ctrl+Alt+A, чтобы немедленно отключить его. Он также выключается, когда это парное соединение закрывается. Утверждения на спаривание остаются отдельными. Команды вводятся в оболочку, которую вы наблюдаете, и не попадают в ее историю: команды на этом компьютере в собственную консоль borg, которая отображается во время их выполнения, поэтому вы можете ответить на приглашение, например, sudo; команды в контейнере в оболочку этого контейнера в представлении Docker. Оболочка сохраняет свою папку и переменные между командами.

Агент также может ввести текст для просмотра: команду в командной строке или сценарий в vim или nano, открытый в консоли. Ничего не запускается: не нажимается Enter, а текст из нескольких строк попадает в виде вставки, которую оболочки и редакторы вставляют без запуска.

### Borg облако

Облако Borg позволяет Claude достичь borg, к которому у него нет SSH-маршрута: сервер, который вы открываете в терминале браузера, контейнер, машина за NAT. Обе стороны подключаются к реле, и реле объединяет их.

1. В borg на сервере нажмите F1, затем C. Первый вариант — `borg pair` со ссылкой; Enter копирует его. Ссылка работает один раз, в течение десяти минут. Под ним находится реле: вставьте туда адрес другого реле и нажмите Enter, чтобы сохранить его и получить через него ссылку.
2. Запустите его в терминале на своем компьютере, где также установлен borg. Он печатает код сопряжения: шесть смайлов, каждый со своим именем, например: `🐱 Cat · 🦁 Lion · 🐎 Horse`.
3. Borg на сервере спрашивает, нужно ли подключаться, показывая имя компьютера и код. Выберите «Да», если коды совпадают. `borg pair` затем предлагает добавить сервер в код Claude, как    `claude mcp add borg-NAME -- borg mcp remote NAME`.

Код получен из зашифрованного рукопожатия, которое только что завершили два борга, поэтому он одинаков на обоих экранах только тогда, когда ваш компьютер разговаривает с сервером. Кто-то, кто получил ссылку и использовал ее первым, покажет серверу другой код и не сможет выбрать тот, который соответствует вашему. Если терминал рисует смайлики уже, чем borg их раскладывает, borg показывает только имена; сравните имена.

С этого момента Claude достигает этой borg всякий раз, когда она там открыта. `borg pair` один перечисляет спаренные серверы, и `borg pair --forget NAME` забывает один; на сервере F8 в диалоговом окне «Удаленный доступ» забывает все сопряженные компьютеры. Через облако borg Claude тоже попадает `download` и `upload`, которые копируют файлы между сервером и вашим компьютером; `borg get NAME:PATH [TO]` и `borg put FROM NAME:PATH` сделайте то же самое со своего терминала. Загрузки ждут вашего одобрения через borg. При каждом одобрении указывается имя компьютера, который запросил.

Соединение шифруется сквозное. Каждый borg хранит в своей папке состояния закрытый ключ, доступный для чтения только вам. При спаривании происходит обмен открытыми ключами, и каждое соединение открывается с привязанным к ним рукопожатием Noise IK, поэтому реле пересылает только зашифрованный текст и не может ответить ни от имени borg. Звонки с другого компьютера можно читать без запроса, как и локальные; Параметры → Плагины → «спрашивать, прежде чем другой компьютер прочитает» заставляет эти чтения тоже ждать одобрения. Borg не поддерживает соединение с реле, если оно не сопряжено или не показывает ссылку для сопряжения, и вообще не поддерживает соединение, когда облако borg выключено в меню «Параметры» → «Плагины».

Borg сохраняет реле в конфиге, как `relay = "wss://relay.example.com"`. Компьютер подключается к серверу через реле, через которое он подключен; после того, как сервер сменит реле, снова выполните сопряжение компьютера. У боргов на одной машине общий ключ, поэтому к реле подключается только тот, кто первым открылся; остальные говорят, у кого облако borg.

Пока агент подключен, **◈ Удаленно** находится в начале строки ярлыка; щелкните по нему, чтобы просмотреть журнал того, что он сделал: что он посмотрел, прочитал, показал и напечатал, а также каждую команду и изменение, одобренные или отклоненные. Borg сохраняет журнал только в памяти до выхода из него; чтобы вообще не вести журнал, отключите его в «Параметры» → «Плагины».

### Запуск реле

`borg-relay` это эстафетные борги встречаются. На сервере Linux, чей домен указывает на него, со свободным портом 443, одна команда устанавливает его как сервис с TLS-сертификатом от Let's Encrypt:

```sh
curl -fsSL https://raw.githubusercontent.com/0xcd21h/borg-commander/main/scripts/install-relay.sh | sudo sh -s -- relay.example.com you@example.com
```

Запустите его еще раз, чтобы обновить.

На Dokploy, Coolify или другом хосте Docker, чей прокси добавляет TLS, запустите образ. `ghcr.io/0xcd21h/borg-relay:latest` и даем ему домен на порту 8080: в Dokploy приложение из этого образа Docker с доменом на порту контейнера 8080 и включенным HTTPS; в Coolify — ресурс из этого изображения Docker с открытым портом 8080 и доменом. Либо тоже принимает [упаковка/реле/docker-compose.yml](../../../packaging/relay/docker-compose.yml) как услуга создания сообщений. Изображение работает `borg-relay --behind-proxy`: прокси-сервер обслуживает HTTPS и пропускает через него WebSockets, а ретранслятор подсчитывает свои ограничения по адресу клиента, в котором сообщает прокси-сервер. `X-Forwarded-For`. Он запускается от имени непривилегированного пользователя и проверяет работоспособность (`GET /health`).

На хосте Docker без такого прокси тот же образ обслуживает сам TLS:

```sh
docker run -d --restart unless-stopped -p 443:443 -v borg-relay:/data ghcr.io/0xcd21h/borg-relay --domain relay.example.com --cache /data
```

За другим прокси, который добавляет TLS, запустите `borg-relay --behind-proxy --listen 127.0.0.1:8080`; используйте его только за прокси-сервером, поскольку реле доверяет адресу клиента, о котором сообщает прокси. Ретранслятор сохраняет ограничения на адрес, серверы и сеансы, размер кадра, пропускную способность, количество байтов на сеанс, время простоя и длину сеанса. Он не хранит ничего, кроме своего сертификата.

Логи реле засчитываются только: раз в минуту при их изменении появляется строка типа

```text
stats: connections=3 servers=2 sessions=1 joined=14 carried=3.2MiB limited=0
```

с соединениями, которые он поддерживает, зарегистрированными серверами и открытыми сеансами, и с момента его запуска сеансы присоединились, байты, которые они перенесли, а также соединения и сеансы, лимит которых был отклонен или завершен. Для отладки, `--log`или переменная среды `BORG_RELAY_LOG=1` для изображения также регистрируется регистрация каждого сервера по началу его ключа, каждый сеанс с передаваемыми им байтами и каждый предел, достигнутый с адресом клиента.

## Поиск, работа и зрители

Ctrl-S открывает быстрый поиск. Введите имя или глобус, например `*.rs`; Вниз и вверх перемещаются между совпадениями, «Вставка» отмечает совпадение, Ctrl-A отмечает все совпадения, а Enter или Esc закрывает поиск. Сопоставление не учитывает регистр, если запрос не содержит заглавные буквы.

F5, F6 и F8 запускают задания копирования, перемещения и удаления. Alt-J открывает список заданий для приостановки или отмены.

Диалоговое окно «Копировать» имеет необязательную опцию **Оптимизация копирования на жесткие диски** флажок. Используйте Tab, чтобы сфокусировать его, и пробел, чтобы переключить его, или щелкните по нему. Он запускается без проверки для каждой копии. В этом режиме небольшие файлы считываются в память пакетами, а затем записываются каждый пакет, что может сократить поиск источника/назначения при копировании на один жесткий диск. Пакеты содержат до 64 МБ файловых данных или 4096 файлов; файлы размером более 1 МБ загружаются нормально. Производительность зависит от диска, файловой системы и кэширования ОС; между отдельными дисками может быть медленнее. В случае конфликта имен: `o` перезаписывает, `s` пропускает, `k` держит обоих, `a` перезаписывает все, `n` пропускает все и Esc отменяет. Копии записываются во временные файлы и после завершения переименовываются.

F3 открывает средство просмотра. В текстовых файлах стрелки и прокрутка PgUp/PgDn `w` меняет упаковку и Esc или `q` закрывается. На изображениях слева/справа или `p`/`n` выберите предыдущее или следующее изображение. Протоколы изображений используются, когда они доступны; другие терминалы отображают цветные блоки.

Ctrl-Q показывает быстрый предварительный просмотр на другой панели. Tab фокусирует его; стрелки, PgUp/PgDn, Home/End и колесо мыши прокручивают документ. Tab или Esc возвращает к списку файлов. Ctrl-L показывает информацию о файле. F3 расширяет предварительный просмотр текста в средстве просмотра; закрытие его возвращает к предварительному просмотру с сохранением вашей позиции, упаковки и исходного режима. Оба используют одну и ту же программу чтения ограниченных файлов, поэтому при открытии большого текстового файла считывается около первой страницы, а не загружается весь файл.

Оба средства просмотра текста выделяют распространенные языки программирования, разметку и файлы конфигурации, включая Rust, Python, JavaScript, TypeScript/TSX, Go, C/C++, Java, C#, Ruby, PHP, Lua, SQL, HTML/CSS, JSON, YAML, TOML, сценарии оболочки и файлы Dockerfile. Markdown открывается в формате по умолчанию. Нажмите `s` или F4 в любом средстве просмотра, чтобы переключить вид исходного кода. Поддерживаются заголовки, выделение, списки, задачи, ссылки, таблицы и изолированные блоки кода. Файлы Markdown размером более 2 МБ открываются как исходные, чтобы ограничить память.

F4 открывает выбранный файл во встроенном редакторе Borg, а Shift-F4 — в `$VISUAL` или `$EDITOR`. Редактор сохраняет окончания строк и отступы файла, подсвечивает код так же, как просмотрщики, и нумерует строки. Shift со стрелками выделяет; Ctrl-C, Ctrl-X и Ctrl-V копируют, вырезают и вставляют через буфер обмена Borg, а вставка из терминала попадает как есть. Ctrl-Z и Ctrl-Y отменяют и повторяют, Tab и Shift-Tab увеличивают и уменьшают отступ, Ctrl-F ищет (F3 — снова, Shift-F3 — назад), а Ctrl-G переходит к строке. F2 или Ctrl-S сохраняют через временный файл, поэтому файл никогда не остаётся записанным наполовину, а если файл изменился на диске после открытия, редактор спрашивает, перезаписать его или перечитать. Esc закрывает редактор, сначала спрашивая о несохранённых изменениях. Файлы, которые не являются текстом UTF-8 или больше 32 МиБ, открываются в просмотрщике.

## Конфигурация

Язык интерфейса выбирается через **F9 → Параметры → Язык**. Доступны английский, упрощённый китайский, португальский (Португалия), испанский и русский. Enter сохраняет выбор, Esc отменяет. Настройка записывается в `config.toml` как `language = "en"`, `"zh-CN"`, `"pt"`, `"es"` или `"ru"`. `BORG_LANGUAGE` имеет приоритет над сохранённой настройкой. Если ни одна не задана, Borg использует `LC_ALL`, `LC_MESSAGES` или `LANG`; для неподдерживаемых языков выбирается английский. Команды, пути, имена файлов и сочетания клавиш не переводятся. Язык руководства независимо выбирается в меню сайта.

Настройки сохраняются в `~/.config/borg-commander/config.toml`или каталог, выбранный `$XDG_CONFIG_HOME` или `$BORG_CONFIG_DIR`. F9 → Параметры → Настройки открывает флажки; Пробел или щелчок переключают настройку и немедленно сохраняют ее. Esc закрывает окно.

```toml
theme = "neon"              # midnight, aurora, neon, classic, paper, ember, or your own
icon-style = "auto"         # auto, nerd, or portable; Ghostty gets rich icons automatically
icon-spacing = 1            # spaces after an icon, 1 to 3
status-line = true
menu-bar = false            # keep the menu bar visible
show-hidden = false
return-to-panels = true    # return after commands launched from the panels
restore-terminal = false    # bring back the shell scrollback on the next start
screensaver = true          # a spinning cube or a glitching logo, picked at random
screensaver-after = 300     # seconds of idle time
update-check = true         # look for a new release once a day
graphics = "auto"           # auto, kitty, sixel, iterm or off
relay = "wss://relay.example.com"  # the relay for borg cloud

[plugins]
git = true
system = true
docker = true
docker-console = true       # the command line follows container panels into the container
agent-log = true            # log what Claude does while Borg runs
agent-cloud = true          # paired computers reach this borg through borg cloud
agent-ask-reads = false     # reads from another computer wait for approval

[search]
exclude = ["*.min.js", "fixtures/large"]  # paths below the search folder, as in .gitignore
artifacts = true            # leave out node_modules, Cargo's target and cache-tagged folders
ignore-files = true         # follow .gitignore, .ignore, .rgignore and .borgignore
history = true              # remember searches for Ctrl-P and Ctrl-N

[index]
roots = ["~/Projects"]      # folders indexed for instant search
refresh-minutes = 15        # rebuild an index once it is this old
```

На местном терминале с настоящим цветом Borg открывается с короткой заставкой логотипа; любая клавиша или щелчок пропускают его. По SSH и на терминалах без true color начинается прямо в панелях.

Папки панели, положение курсора, разделение, режим листинга и сортировка сохраняются в `~/.local/state/borg-commander`или местоположение, выбранное `$XDG_STATE_HOME` или `$BORG_STATE_DIR`.

Во время работы Borg сохраняет сценарии интеграции оболочки и файлы, скопированные из контейнеров, в `$XDG_RUNTIME_DIR/borg-commander`, или `borg-commander-<uid>` во временной папке. Только вы можете открыть его; тот, который создал кто-то другой или в который могут войти другие, заменяется новым именем. Это `TTL` Файл начинается со времени, до которого он используется: каждый запущенный borg сдвигает это время на день вперед каждый час, поэтому, как только оно пройдет, папку можно удалить.

Входят пользовательские темы `~/.config/borg-commander/themes/`. Тема может расширять встроенную тему:

```toml
name = "Deep Space"
extends = "neon"

[styles]
cursor = { fg = "#0b0b16", bg = "#00e5ff", bold = true }
dir = { fg = "#b388ff", bold = true }
```

Информацию о создании, тестировании или участии см. [Развитие](../../../DEVELOPMENT.md).

## Небольшое отвлечение

Откройте «О программе» с помощью F1 и введите `2048` играть в модальном режиме. Клавиши со стрелками перемещают, U отменяет последний ход, R начинает новую игру, а Esc закрывает ее. Достигните 2048, затем нажмите Enter, чтобы продолжить игру. Доска и лучший результат сохраняются между сеансами.


## Активность и память

**Alt-M** или **Команда → Монитор активности** открывает монитор процесса. Входящий в комплект системный плагин включен по умолчанию, его можно отключить в меню «Параметры» → «Плагины». Список процессов занимает активную панель, а напротив него — обзор памяти выбранного процесса. **Enter** или двойной щелчок открывает этот процесс в окне над монитором: его карта памяти с одной стороны и предварительный просмотр байтов выбранного региона с другой. **Esc** закрывает его. **Tab** переключает фокус. **Alt-W** или **[+]** кнопка разворачивает выделенную область; **[=]** восстанавливает раскол и **[-]** скрывает монитор. Выборка выполняется раз в секунду, пока монитор открыт; закрытие останавливает выборку. Проверки памяти временно приостанавливают выборку до получения результата.

В списке показаны CPU, резидентная память, прирост памяти и скорость чтения/записи диска. CPU 100% означает одно занятое ядро. Общие резидентные страницы могут присутствовать более чем в одном процессе, поэтому значения процесса RAM не следует добавлять в качестве уникального системного итога. Первая выборка CPU и скорости ввода-вывода недоступна до тех пор, пока не поступит второе наблюдение.

Щелкните заголовки процессов для сортировки; дважды щелкните процесс, чтобы открыть его карту памяти. В обзоре показаны текущая резидентная память, наблюдаемый пиковый объем памяти, изменение с момента начала мониторинга, CPU, виртуальное адресное пространство и диаграмма резидентной памяти за последние 60 секунд. Общие итоговые значения Footprint, замененные, частные и общие отображаются после считывания карты памяти, и платформа сообщает о них. **Enter** в панели памяти открывается ее карта памяти. Карта памяти представляет собой измерение, проводимое по запросу. Обновите его с помощью R после того, как процесс изменит свои сопоставления.

Карта имеет три столбца:

- **След** — это память, отведенная только этому процессу: страницы, которые он записал, плюс страницы, выгруженные или сжатые. Это цифра, за которой следует следить за утечками, и на macOS она соответствует значению Activity Monitor. *Память* столбец.
- **Резидент** это страницы в RAM сейчас, включая страницы, используемые другими процессами.
- **Нанесено на карту** — это адресное пространство, включая резервирования. Это не RAM.

Процесс может отображать гигабайты, в основном системные библиотеки, используемые всеми остальными процессами, при этом его объем составляет несколько мегабайт. Регионы сначала группируются по назначению: куча и выделения, стеки потоков, собственный код и данные программы, общие библиотеки, отображаемые файлы, общая память, системные и другие выделения, а также зарезервированные диапазоны и защитные элементы. Группы и их участники упорядочены по площади, оговорки оставляются в последнюю очередь. Библиотеки и сопоставленные файлы содержат по одной строке для каждого файла; разверните файл, чтобы увидеть его регионы. Имена групп выводятся из меток операционной системы. Выбор группы или файла объясняет это и показывает долю занимаемой площади и ее крупнейших членов. Enter или Вправо разворачивает группу или файл; Влево сворачивает его или строку вокруг выбранной строки. G переключает между сгруппированными и необработанными списками.

**1 память** и **2 Открытые файлы** переключайте вкладки проверки или щелкайте их метки. Список открытых файлов включает дескриптор, режим доступа, тип и путь или конечную точку; на другой панели отображаются полные сведения, размер файла и текущее смещение, если оно доступно. На macOS он также включает такие записи, как `cwd` (текущий каталог) и `txt` (сопоставленный исполняемый файл). R обновляет список. При переключении вкладок позиции в списке сохраняются. Ограничения доступа предлагают существующую явную повторную попытку администратора. Содержимое файла не считывается через дескрипторы процессов.

При выборе читаемой области в противоположной панели автоматически захватывается до 64 КиБ её содержимого. Если начало области состоит только из нулей, захват читает дальше до первой страницы с данными, а строка над байтами показывает, где в области находится окно. Быстрые перемещения объединяются с небольшой задержкой; выбор другой области очищает прежний предпросмотр и отменяет его ожидающее чтение. Для нечитаемых областей показывается сообщение без попытки чтения. Нажмите **Tab** или **Enter**, чтобы прокручивать предпросмотр. **Esc** там переводит фокус на список; **Esc** из карты возвращает к списку процессов с сохранённым курсором и фильтром.

Серии нулевых строк сворачиваются в одну строку, например «· 60K нулевых байт ·». **]** и **[** переходят к следующему и предыдущему блоку данных, а **>** и **<** захватывают следующие и предыдущие 64 КиБ области. **H** переключает шестнадцатеричное и текстовое представление, **R** заново захватывает показанное окно, а **D** выделяет отличия от предыдущего захвата того же процесса и адреса. Текстовое представление показывает печатный ASCII и заменяет точки другими байтами. Снимки — это живые наблюдения; процесс не приостанавливается, поэтому захват не является атомарным изображением всего его состояния. Они остаются в памяти, если не экспортируются явно. **E** экспортирует необработанные байты в каталог активной файловой панели, используя новое имя файла и права доступа к файлу только для владельца. Существующие файлы никогда не перезаписываются.

**M** переключает предварительный просмотр между байтами и картой страниц области: по ячейке на каждую страницу в 4 КиБ или на каждую серию страниц в большой области, с отметкой о том, что в ней лежит: указатели в собственную память процесса, текст, текст UTF-16, код, сжатые или зашифрованные данные, другие данные, заполнитель, нули и страницы не в памяти. Легенда показывает долю области, которую занимает каждый вид. В карте с фокусом стрелки, **PgUp**, **PgDn**, **Home** и **End** двигают курсор, а **Enter** открывает страницу под ним в байтах. Области больше 16 384 страниц просматриваются равномерной выборкой. В Linux карта спрашивает у системы, какие страницы находятся в памяти, и не читает остальные, поэтому не возвращает выгруженные страницы и не трогает новые; в macOS нетронутые страницы читаются как нули. Виды определяются только по байтам, поэтому считайте их подсказкой, а не приговором.

Нажмите **/** на панели памяти или **Ctrl-F** из любой панели для поиска в памяти. Выберите режим, соответствие регистру и либо читаемую память процесса, либо текущий снимок. **Текст** ищет UTF-8, UTF-16 (оба порядка байтов) и UTF-32 (оба порядка байтов). **Юникод** также нормализует символы совместимости и комбинированные последовательности: например, `𝐁𝐨𝐫𝐠` спички `Borg`. Это не относится к несвязанным буквам, которые просто выглядят одинаково. **Шестигранник** принимает пары байтов, такие как `42 6F 72 67`.

Совпадения занимают панель списка и показывают их исходный адрес, кодировку и регион. При выборе совпадения окружающие его байты просматриваются на противоположной панели, при этом совпадающие байты выделяются. Enter фокусирует предварительный просмотр; Esc возвращает фокус на совпадения. Esc из совпадений восстанавливает предыдущую карту или список процессов. При поиске в сохраненном снимке используются захваченные байты без чтения запущенного процесса. Поисковые процессы считываются порциями, сообщают о недоступных байтах и ​​прекращаются после 2000 совпадений или 60 секунд. **N** продолжает с этой позиции; **Ctrl-C** останавливается с сохранением результатов. В отчетах о покрытии различаются искомые и недоступные байты. Процесс может изменить свою память во время поиска.

Ограниченное чтение карт памяти или снимков, а также частично недоступный поиск **А: Администратор**. При нажатии macOS откроется окно авторизации в системе; на Linux он использует `pkexec` и нуждается в доступном агенте авторизации. Возвышается лишь недолговечный помощник осмотра. Borg продолжает работать нормально, а помощник возвращает только данные карты или ограниченные байты. macOS защита процессов и Linux политика безопасности по-прежнему могут запрещать доступ; Borg показывает сбой и позволяет использовать обычный монитор процесса.

Идентификатор процесса включает время его начала, поэтому повторно используемый PID не наследует историю другого процесса. Карты памяти, выходные данные проверки, снимки и история ограничены. Borg Commander остается видимым в правом нижнем углу, включая консоль, средство просмотра, монитор, диалоговые окна и заставку.
