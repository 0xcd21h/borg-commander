## 安装

从 [GitHub Releases](https://github.com/0xcd21h/borg-commander/releases) 下载二进制程序，或在 macOS、Linux 上运行安装脚本。支持 Intel 和 ARM：

```sh
curl -fsSL https://raw.githubusercontent.com/0xcd21h/borg-commander/main/scripts/install.sh | sh
```

安装脚本会校验压缩包的校验和，并将 `borg` 安装到 PATH 中的目录，因此仍在当前终端中运行。若 `~/.local/bin` 已在 PATH 中，则使用该目录；若 `/usr/local/bin` 可写（例如容器中的 root 用户），则使用它；否则使用 `~/.local/bin`，并将其添加到 Shell 启动文件。安装后会启动 Borg；设置 `BORG_NO_RUN=1` 可跳过启动，`BORG_INSTALL_DIR` 可指定安装目录。若同一版本已安装，再次运行会跳过下载。也可使用 Rust 1.97 或更高版本从源码构建：

```sh
cargo install --locked --git https://github.com/0xcd21h/borg-commander borg-app
```

已准备 Homebrew 支持。tap 仓库发布后可运行：

```sh
brew install 0xcd21h/tap/borg-commander
```

在要浏览的文件夹中运行 `borg`。F10 退出；Ctrl-O 从命令行返回文件面板。通过 `borg update` 更新下载的程序；若使用 Homebrew 或 cargo 安装，请使用相应的包管理器更新。`borg --version` 显示已安装的版本。

## 主题和图标

使用 F9 → 选项 → 主题选择主题。请参阅 [主题画廊](../../../README.md#themes) 对于Midnight、Aurora、Neon、Classic、Paper和Ember。

主题使用固定颜色，因此终端调色板自定义不会改变其外观。没有真彩色的终端使用 256-colour 调色板中最接近的颜色。

文件图标始终显示。 Ghostty 自动使用更丰富的Nerd Font 图标。其他终端默认为可移植符号： `/` 对于文件夹， `@` 对于链接，以及 `*` 对于可执行文件。套装 `icon-style = "nerd"` 在另一个终端中使用具有合适字体的丰富图标，或者 `icon-style = "portable"` 强制可移植符号。默认情况下， `"auto"`，适应终端，而不将该检测保存为字体首选项。

发布档案包括 **Borg Mono**，带有 Nerd Font 图标的等宽字体。安装常规字体和粗体字体 `fonts/`，在终端中选择 Borg Mono，然后选择 `"nerd"` 图标风格。 Borg 无法更改终端的字体。安装程序将它们保存在 `${XDG_DATA_HOME:-~/.local/share}/borg-commander/fonts`; Homebrew 让他们留在里面 `$(brew --prefix)/share/borg-commander/fonts`.

## 集合和递归搜索

“搜索”菜单可打开集合和递归文件名搜索。两者都使用带有源路径的可排序结果以及现有查看器和快速预览。

- **Ctrl-F：** 在当前文件夹下递归搜索。所有词都必须匹配：`main rs` 能找到 `main.rs`，`a | b` 则匹配其中任意一个。全小写的词不区分大小写；含大写字母的词严格区分大小写。也可以使用 `*.log` 这样的 glob、带引号的短语、带斜杠的路径（如 `src/lib`），以及用 `-word` 排除匹配项，还可以使用过滤条件 `ext:rs,toml`、`type:file`、`type:dir`、`type:link`、`size:>10M`、`size:1M..50M`、`mod:<7d`（最近一周内修改）、`mod:>1y` 和 `in:src`（路径中任意位置的文件夹）。最近的搜索列在表单下方，同一文件夹中的搜索优先；点击其中一项，或在查询框中按 Ctrl-P 和 Ctrl-N，即可选用。无论 glob 的大小写如何，任何文字的名称都能匹配；无论文件系统如何存储带重音的字母，也都能匹配。靠近搜索文件夹的匹配项先显示，同时继续读取其余部分。
- **Alt-K：** 在另一个面板中收集标记的文件或当前文件。添加引用不会复制文件的内容。
- **Alt-V：** 从可滚动列表中选择已保存的集合，其中包含条目计数和大小估计。按 F7 或 N 创建一个。集合在重新启动后仍然存在Borg。
- **Esc：** 隐藏结果，保留光标、滚动、标记、过滤和分组。
- **Alt-Shift-R：** 恢复隐藏视图。隐藏时扫描会继续。
- **Alt-D — 文件夹大小：** 按总大小或文件数查找文件夹，默认情况下包括隐藏文件。它打开Ctrl-F对话框设置为 *文件夹总数*;切换   *寻找* 在两者之间移动。 Ctrl-C 停止扫描。
- **Alt-S：** 计算所选文件夹的大小。 **Alt-Shift-D：** 打开当前文件夹的大小树。
- **Alt-W：** 最大化或恢复活动结果窗格。默认情况下，结果在普通窗格中打开。标题栏 `[+]` （最大化）， `[=]` （恢复），以及 `[-]` （折叠）控件是可点击的。折叠隐藏视图； Alt-Shift-R 恢复它并保留其布局和选择。
- **Ctrl-S：** 按名称或源路径过滤结果。一个空的过滤器显示了一切。

单击列标题可对其进行排序或反转。左/右菜单还提供排序功能；搜索添加了按文件夹或文件类型对源文件夹进行排序和分组的功能。组标题上的Enter将其折叠；插入标记其匹配的成员。标记能够经受住排序和过滤；页脚也计算过滤器隐藏的标记文件。

F3和Ctrl-Q打开真正的源代码。 F5 复制到真实目的地；如果目标面板是集合，则会添加引用。 F6需要一个真实的目的地。 F8 从集合中删除引用。在搜索结果中，F8要求删除原件。确认后，Shift-F8还会从集合中删除原件。当文件夹及其内容都被标记时，该文件夹将被发送到作业一次。显示原始文件在另一个面板中打开其源文件夹。向左或Esc隐藏结果； Alt-Shift-R 在同一个地方恢复它们。即使 shell 有待处理的命令，Tab 也会切换虚拟面板。 shell 保留一个真实的工作目录。 F10 退出前总是先询问。

搜索读取文件名和元数据，具有可取消的工作进程，每次搜索最多 20,000 个匹配项。上下文行显示完成、错误、跳过的条目以及是否达到该限制。隐藏文件夹遵循显示隐藏文件。搜索保留在起始文件系统上，并且不会通过目录符号链接进行递归。搜索窗口可以将结果限制为文件或文件夹并设置最小大小。选择 **文件夹总数** 在按名称、大小或最小文件数过滤之前测量所有后代文件。它保留最大 20,000 个匹配文件夹并按内容大小排序；单击“文件”可按文件数量排名。使用如下模式 `node_modules` 或 `*cache*`, 或 `*` 检查所选根目录下的所有内容。文件内容总数，不保证可恢复的磁盘空间。嵌套文件夹行重叠。符号链接永远不会被跟踪，扫描保留在启动文件系统上，并且包含自身的文件夹（通过绑定安装或硬链接文件夹）仅输入一次；这种边界和不可读或被排除的子项使总数不完整，用 ≥ 表示。目录扫描使用元数据并且不读取文件内容。测量后结果出现；扫描仍然可以取消。 **文件夹大小树** 显示当前面板中的根总计及其子文件夹。向右扩展分支或进入扩展分支；向左折叠它或选择其父级。 Enter 打开真实文件夹。单击分支箭头可折叠或展开，或单击列标题可按名称、大小或文件计数对同级进行排序。 Esc 隐藏树； Alt-Shift-R 恢复其分支、标记和光标。文件操作使用真实路径，并且标记父级和子级仅将父级发送到复制或删除作业。

勾选 **排除构建输出、缓存和被忽略的文件** 时，按名称搜索会跳过生成的文件夹：`node_modules`、`.git`、Python 缓存和虚拟环境、`target` 和 `dist` 等文件夹（当旁边有构建文件时，如 `Cargo.toml`、`package.json`），以及带有 `CACHEDIR.TAG` 文件的任何文件夹。被 `.gitignore`、`.ignore`、`.rgignore` 或 `.borgignore` 排除的文件以及 `[search] exclude` 中的 glob 也会被跳过。在搜索对话框中按 F4，或点击 **F4 编辑**，可更改排除的内容：开关生成的文件夹和被忽略的文件，并添加（Ins）、编辑（Enter）或删除（Del）模式。更改会保存在配置文件中。自身名称匹配的被跳过文件夹仍会出现在结果中，上下文行会统计跳过的文件夹数量。`excluded:yes` 可一次性搜索所有内容，`hidden:yes` 会包含隐藏文件。大小扫描总是读取全部内容。在 macOS 上，从上层开始的搜索和大小扫描会跳过 `~/Library/Containers` 和 `~/Library/Group Containers`；macOS 会暂停其中的每次读取，直到有人回答是否允许访问其他应用的数据。从其中某个文件夹开始的搜索会读取它。搜索历史保存在这台计算机上，只有您能读取；设置 `history = false`（位于 `[search]` 下）可停止保存。

**搜索 → 为即时搜索索引此文件夹** 会为当前文件夹下的所有名称建立索引，因此在该文件夹或其任意子文件夹中按 Ctrl-F 会立即得到结果；上下文行会显示索引的建立时间。Borg 启动后以及索引超过 15 分钟时，索引会在后台重建，新索引完成前由旧索引继续回答。不排除任何内容或使用其他排除规则的搜索会改为遍历文件夹。再次选择该项可停止索引并删除索引。索引与大小扫描一起保存在缓存文件夹中；配置中的 `[index]` 列出被索引的文件夹。

要在保持普通文件面板打开的情况下测量尺寸，请按 **Alt-I** 或选择 **搜索 → 计算背景尺寸**。 Borg 扫描当前目录下的每个文件夹，包括隐藏文件，并在完成后填写文件夹总数。您可以在控制台运行时导航或使用它。仍在测量的文件夹显示标记的运行总数不断增长 `≥`，当您离开文件夹并返回时，总计会保留。面板页脚显示进度； **Alt-I** 再次，或单击页脚，停止扫描并保留迄今为止测量的总数。启动复制、移动或删除作业会停止正在进行的尺寸扫描。完成的扫描与大小树和空间分析共享其缓存。

完成的扫描保存在本地。空间分析和文件夹树都重复使用相同根和隐藏文件策略的已保存扫描。重新打开测量的根会立即使用该快照： `~` 标记缓存的尺寸，并在树上方显示测量日期。 **Ctrl-R** 在任一尺寸视图中重新扫描； **Ctrl-C** 取消。前一棵树在刷新期间保持可见，并且在取消或失败后仍然存在。普通文件夹列表还显示可用的缓存总数。 Borg 之外的更改可能会使它们过时；导航不会触发递归扫描。 Borg 复制、移动和删除作业会使与其更改路径重叠的快照无效。

本地 SQLite 索引保留每个测量的文件夹最多 16 个根。当树枝伸展时，按需加载子目录；一个分支最多可显示 20,000 个文件夹，平面空间分析可保留最大 20,000 个匹配项。这些显示限制不会停止扫描或减少测量总数。 “此文件夹中的文件”行占直接存储在展开文件夹中的字节。错误和跳过的子树将总计标记为不完整。缓存文件位于 `~/.cache/borg-commander`, 尊重 `XDG_CACHE_HOME`; `BORG_CACHE_DIR` 覆盖位置。它们是一次性测量，与集合分开。每个路径的硬链接文件计数一次。这些是逻辑内容大小，而不是物理或可恢复磁盘使用情况。

Git 和归档操作当前可在真实目录面板中进行。使用“显示原始内容”来访问它们以获取收集的文件。

## 按键

两行快捷方式栏位于命令行下方。功能键位于第一排；搜索、收藏和其他上下文快捷方式位于第二个。两行都是可点击的。通知暂时取代第二行。

| 钥匙 | 行动 |
| --- | --- |
| 向上、向下、PgUp、PgDn、Home、End | 移动 |
| Enter，右 | 打开文件夹/运行或查看文件 |
| 左 | 转到父文件夹 |
| Tab | 切换面板，或聚焦快速预览/返回文件列表 |
| Ctrl-O | 显示外壳/返回面板 |
| Alt-I | 在后台计算文件夹大小/停止计数 |
| Ctrl-S | 在文件夹中快速查找 |
| Ctrl-Q | 快速查看：另一个面板预览光标下的文件（文本、图片或文件夹） |
| Ctrl-L | 信息：另一个面板显示大小、模式、所有者、日期和可用空间 |
| 插入，Ctrl-T，Shift-Up/向下 | 标记文件 |
| `+` `-` `*` | 按模式选择、取消选择或反转（`*.rs`, `build/`) |
| Alt-Enter | 将标记的名称（或当前名称）放在命令行上 |
| Ctrl-Insert / Alt-Shift-Insert | 复制标记的名称 / 它们的完整路径 |
| Shift-Enter, Ctrl-J | 在命令行光标处插入换行符； Enter运行命令，Ctrl-C清除它 |
| Alt-A / Alt-Shift-A | 将此面板/其他面板的文件夹路径放在命令行上 |
| Shift-PgUp / Shift-PgDn | 滚动控制台输出历史记录 |
| Shift-Home / Shift-End | 最旧的控制台输出/返回实时提示符 |
| Ctrl-P / Ctrl-N, Ctrl-R | Shell 历史记录：上一个/下一个命令、搜索（由您的 shell 处理） |

| F7 | 制作文件夹 |
| F8 | 删除 |

当命令行为空时，Tab、Enter、Home、End、Left 和 Right 作用于面板。输入命令后，这些键就会进入 shell。 Ctrl-P、Ctrl-N和Ctrl-R使用 shell 的命令历史记录。 Shift-Enter（或Ctrl-J）插入换行符而不运行命令。键入和调用的多行命令会扩展相同的提示区域，缩小面板并保持光标可见。 shell 保留了常用的编辑和完成键。

复制的内容会通过终端进入您计算机的剪贴板，通过 SSH 以及在您控制的镜像中也是如此。Borg 还会保留最近 20 次复制：Ctrl-V 或 Shift-Insert 会把最新一次粘贴到 Borg 自己的输入框中，例如对话框和内存搜索，即使终端无法访问您的剪贴板也可以。在命令行中 Ctrl-V 仍归 shell 使用，因此请用终端的粘贴键在那里粘贴。文件菜单为没有 Insert 键的键盘提供这两种复制；对终端来说过大的复制内容只保留在 Borg 中。

如果您的终端保留 F 键，请按 **Esc，然后是一个数字** 1.5秒内：Esc1–9是F1–F9； Esc 0 是F10。例如，Esc 9 打开菜单，Esc 5 副本。当Borg等待数字时，功能键行显示要按下的数字。 Esc 首先关闭打开的内容（通知、结果、快速视图或信息）；第二个Esc取消。当 Alt 到达终端时，Alt-1–0 也有效。在macOS上，如果需要，在终端中启用选项作为元。

## 鼠标和控制台

单击一行将其聚焦，双击将其打开，然后右键单击将其标记。单击菜单栏或底部操作即可使用它们。轮子穿过面板入口。

对话框同样支持鼠标。单击列表中的一行即可选中；在主题和语言选择器、远程主机和远程访问中，再次单击即可确认。滚轮可在主题、设置和任务等列表中移动。对话框边框中列出的按键也可以单击：单击 **Esc 关闭** 即可关闭对话框，单击问题中的按钮即可作答。在列表、选择器或关于窗口之外单击会将其关闭，而表单和问题会一直保持打开，直到你作答。

Ctrl-O 在面板和控制台之间切换。在您键入或打开控制台之前，shell 会跟随活动面板的文件夹。在zsh中，它会默默地更改文件夹并重新绘制提示；在bash和fish的简短 `cd` 命令出现在控制台中。命令和 Ctrl-C 使显式打开的控制台保持可见。 “命令后返回面板”适用于从面板启动的命令。在 shell 提示符下，Option/Alt-Left 和 Option/Alt-Right 按单词移动。

在控制台中，滚轮滚动输出历史记录，而不更改正在键入的命令。 Shift-PgUp/PgDn 滚动一页； Shift-Home 转到最旧的输出； Shift-End 返回实时提示。键入也会返回到实时提示。使用终端的选择手势（通常为 Shift-drag），然后使用其正常的复制快捷方式来复制可见输出。

## Git 插件

Git 是一个捆绑插件，默认启用。 F9 → 选项 → 插件打开其复选框；关闭它会隐藏 Git 菜单和状态列并停止后台状态扫描。它需要您的 PATH 上的 Git。

在存储库内，面板显示分支以及每个文件旁边的两个字符的状态。左边的字符描述了索引（阶段性变化）；右边描述了工作树。 `M` 意味着修改， `A` 补充说， `D` 已删除， `R` 重命名， `??` 未追踪的，以及 `U` 冲突。文件夹总结了其下方的更改。干净和忽略的文件没有标记。在存储库之外，文件名使用额外的空格。

Git 菜单提供存储库状态、未暂存和已暂存的差异、最近的提交以及标记文件的暂存/取消暂存（或未标记任何内容时的当前文件）。差异和历史记录在普通查看器中打开。取消暂存会保留工作文件。状态在导航、命令和 Git 操作后刷新一次，并且在面板空闲时每五秒刷新一次。 Git 菜单中的刷新状态会立即重新扫描。

## Docker插件

**Alt-C** 或 **命令 → Docker** 列出活动面板中的容器，按 Compose 项目分组，最后是 Compose 之外的容器。另一个面板显示所选容器：其状态、端口、网络、安装、命令和重新启动策略，以及实时 CPU、内存、网络和磁盘使用情况以及最后一分钟的图表。在项目上，它显示项目的文件夹、其容器以及它们的组合使用。 Esc 关闭视图。

停止和重新启动首先询问。在项目中，操作仅涉及它更改的容器，因此“开始”会启动已停止的容器。

**F** 在正在运行的容器上关闭 Docker 视图并在该面板中显示容器的文件系统（从其工作目录开始）。面板标题为容器命名。另一个面板保留其主机文件夹，因此 **F5** 无论哪种方式都可以复制，并且 **F3** 意见, **F7** 创建一个文件夹并 **F8** 删除容器内的内容。搜索、大小、预览和编辑保留在主机上。 **Alt-C** 返回Docker视图； `..` 在容器的根目录将面板返回到之前显示的主机文件夹。浏览需求 `sh` 在容器中，因此无法列出没有 shell 的最小镜像。

在容器的文件下，命令行跟随面板：它成为该容器的 shell，在面板的文件夹中启动，容器的名称位于其提示符的开头。命令在容器内运行，面板在完成后刷新，并且 `cd` 面板移动。 Ctrl-O 显示容器的控制台，标记为 **▣ 名称控制台**;在主机面板上，命令行和Ctrl-O又是主机的，您在其中输入的任何内容都会保留。容器的 shell 与 Docker 视图中的 Shell 选项卡相同。

关闭 **Docker — 命令行跟随容器面板** 在选项 → 插件中将命令行保留在主机上。在容器的文件下，它会变暗并被标记 **⌂ 主机**，并且 Enter 在主机面板处于活动状态之前不会运行任何内容，因此命令永远不会在错误的机器上运行。

**E** 在容器中打开一个外壳（当图像有它时为bash，否则 `sh`）在详细信息面板的 Shell 选项卡上，并将您的按键（包括功能键）发送给它。 **Alt-1** 显示概述和 **Alt-C** 返回列表；鼠标滚轮滚动其历史记录。当您查看其他容器、关闭 Docker 视图或使用主机控制台时，shell 会保持运行，并且其容器会被标记 `›_` 在列表中并计入 Alt-C 快捷方式。当你退出它时，当它的容器停止时，或者当 Borg 退出时，它会关闭，当 shell 打开时，它会首先询问。该插件使用 `docker` CLI 及其当前上下文，因此它可以与 Docker Desktop、OrbStack、Colima 和远程引擎等一起使用。可以在选项 → 插件中将其关闭。

## 时间机器排除项

在 macOS 上，**Alt-T** 或 **命令 → 时间机器** 显示时间机器在备份中排除的内容，并可以更改。面板用 ⊘ 标记自身被排除的条目，页脚会统计它们，或说明整个文件夹不会被备份。**Ctrl-L** 信息显示时间机器如何处理光标下的项目。

窗口有三个标签页；**1**、**2**、**3** 或 **Tab** 在它们之间切换。**所选项** 列出已标记的项目，或光标下的项目。**此处缓存** 在面板的文件夹中查找缓存和构建文件夹，例如 `node_modules`、`target`、`.venv` 以及含有 `CACHEDIR.TAG` 的文件夹，按大小从大到小排列，并合计仍在备份的部分。**全部排除项** 按类型列出 Borg 能找到的所有排除项：Spotlight 已知的标记项目和面板文件夹中的标记项目、固定路径、被排除的宗卷，以及 macOS 自行排除的位置。

**Space** 或 **Insert** 标记行，`*` 反转标记。**E** 通过在项目本身上设置标记来排除已标记的行或光标下的行：无需密码，标记会随项目移动，但删除并重新创建文件夹的工具会丢失该标记。**P** 改为排除路径，无论那里是什么都会保持排除，并会在系统对话框中要求输入密码。**I**、**Delete** 或 **F8** 重新包含项目。被排除文件夹中的项目，需要包含该文件夹才能重新备份；macOS 自行排除的内容无法更改。

在全部排除项中，**A** 排除你输入的路径，即使那里还没有任何内容。**R** 重新搜索，**Enter** 在活动面板中显示该项目，**Esc** 关闭窗口。排除或包含宗卷也需要输入密码。时间机器可能需要在系统设置 › 隐私与安全性中为你的终端开启完全磁盘访问权限，才能说明它如何处理某些文件夹；在此之前它们显示为未知。在其他系统上，该菜单项会被隐藏。

## Claude和其他代理人(MCP)

`borg mcp` 让 AI 代理（例如 Claude）在您打开的 borg、您的计算机或通过 SSH 访问的服务器上工作。除了borg之外不需要安装任何东西：代理启动 `borg mcp` 它本身通过服务器的 SSH 连接到在那里打开的 borg 会话。服务器不需要开放端口，也不需要互联网访问。

通过命名工作空间， `borg sessions list` 显示他们的身份证件和姓名； `borg sessions create NAME` 加一，并且 `borg --session NAME` 打开它。 `borg mcp` 可以打电话 `list_sessions`,
`list_remote_sessions`, 和 `use_session` 为该 MCP 连接选择一个目标。工具调用还可以提供 `session` 一键覆盖的 ID。所选目标对该 MCP 连接保持私有。

`borg service install`, `enable`, 和 `start` 设置可选的后台服务。它拥有机器的配对连接，并在终端断开时保持指定会话的运行。 `borg service attach NAME` 重新连接到一个。 Ctrl-] 分离但不结束其外壳。使用 `borg service stop`, `disable`, 或 `uninstall` 来控制服务生命周期。在没有 systemd 的容器中，让容器的进程管理程序运行 `borg service run`;的 `install` 和 `enable` 命令需要 Linux 上的 systemd 主机。

配对后， `borg --remote MACHINE:SESSION` 在左侧本地面板中打开该会话的文件系统。 Enter或F3通过临时本地下载预览远程文件。 **F5** 在本地和远程面板之间或两个配对主机之间复制标记的文件和文件夹。目标对话框标识客户端或主机。副本作为后台作业运行，具有字节进度、暂停/取消以及覆盖、跳过或保留两种选择。文件夹包括空文件夹和符号链接；保留常规文件的可执行权限和修改时间。仅当文件的内容完全到达后，文件在其最终目的地才变得可见。远程面板不支持 F6 移动和 F8 删除。右侧面板仍保留在您的计算机上。与 **选项 → 插件 → 关注** 启用，命令行和 **Ctrl-O** 在远程主机上使用交互式 shell。它的终端是本地渲染的；键、粘贴、Ctrl-C和终端程序远程运行。切换面板时，每个远程会话都会保留自己的 shell 和未完成的命令行。选择客户端面板将恢复本地 shell。使用备用屏幕的应用程序和使用原始输入的前台应用程序，例如 `top`，在运行时接收所有键，包括Ctrl-O。终端大小调整到达远程 PTY。使用应用程序自己的密钥退出应用程序（`q` 在 `top`）；如果您从面板命令行启动它，则Borg返回到面板，或者如果您在那里启动它，则使远程控制台保持打开状态。遥控器Borg自己的面板和外壳独立于该控制台。使用 `borg get MACHINE/SESSION:PATH [TO]` 和 `borg put FROM MACHINE/SESSION:PATH` 用于文件传输。在本地Borg，按 **Alt-H**，使用底部 **远程主机** 快捷方式，或选择 **F9 → 远程 → 浏览主机和会话...** 查看配对的计算机及其命名会话。 Enter 在打开选取器的面板中打开所选会话的文件，替换该面板之前的位置。在选择器中按 **M** 镜像其屏幕；按 **R** 刷新列表。 **Tab** 之间切换 **主办方** （传出访问）和 **客户** （传入访问）。客户端列出与此Borg配对的计算机、它们的公钥指纹、它们是否已连接以及它们的连接计数。即使镜像使用多个连接，一台计算机也会出现一次。当选取器打开时，状态会更新，包括在其连接由后台服务拥有的会话内。配对是定向的：允许的客户端不会自动成为该Borg可以浏览其文件的主机。当连接所有者无法报告其状态时，已配对的客户端仍会显示，并标注 **连接状态不可用**。当镜子连接时，选择器会显示动画状态并 **Esc** 立即取消。连接的每一步都有 10 秒时限，整个尝试最多 30 秒。尝试失败时，选择器保持打开并指出失败的步骤；**M** 重试所选会话。在选择器中， **F2** 重命名该主机上每个会话的选定主机标签； **Shift-F2** 重命名选定的会话标签。这些标签保存在此客户端上，并显示在选择器、面板标题和控制台页脚中。将名称留空以恢复原始名称。详细信息保留原始主机和会话名称。标签绑定到配对主机的密钥和会话 ID；远程主机上的命令目标和名称保持不变。

在不可用的主机上按 **F8** 会在此客户端上忘记它的配对。**Shift-F8** 即使主机在线也会忘记所选主机。确认对话框默认选择 **否**。忘记主机会关闭此客户端上该主机的面板和控制台；主机上的会话和文件会保留。客户端的身份及其其他配对保持不变。重新配对即可再次连接。

**F8** 或 **删除** 确认后删除选定的主机会话，默认为 **否**。删除会关闭该会话及其远程控制台，并删除其保存的Borg面板和终端历史记录；保留主机上的文件和文件夹。默认会话受到保护。当前托管连接的独立会话无法自行删除；在主机上关闭它并首先在另一个会话中运行Borg。删除失败会使会话保持可见以便重试。服务管理的会话在其保存的状态被删除之前停止，并且服务不会重新创建它们。

选择器区分传出主机和传入客户端；相同的Borg可以充当这两个角色。远程菜单还提供 **镜面主机** 和 **作为主机分享这个Borg...**。选择器显示每个主机的Borg版本；选择会话会显示操作系统/体系结构、后台服务或终端模式、请求延迟和中继地址。主机会同时检查，因此不可用的主机不会向其他主机隐藏结果。无法报告版本的主机显示 **版本不可用**；中继的版本不是主机的版本。请在两台计算机上保持 Borg 为最新版本：缺少某项远程功能的主机会显示升级提示。

远程文件夹分块到达，并显示加载动画和已接收的条目数；导航会取消该请求。`borg mirror MACHINE:SESSION` 在本地终端中显示远程会话的实时屏幕； Alt+Shift+M 使用远程面板从本地 Borg 打开同一个镜像。 **Ctrl-G** 离开镜像并返回本地面板：按住 Control 并按 G。您也可以单击底部横幅线。镜子保持其控制状态在上面一行可见； Ctrl-]也退出。 `--take` 明确地从另一个查看者那里获取控制权。一个常规的 `borg` 或 `borg --session NAME` 可以在运行时进行镜像；不需要后台服务。其本地终端仍然可见，并且本地键盘或鼠标输入从镜像收回控制权。镜子遵循主机终端的布局和剪辑以适合较小的客户端窗口；扩大客户规模揭示了其余的事情。可选的后台主机在原始终端关闭后使会话保持活动状态，并允许控制客户端调整其 PTY 的大小。如果另一个终端控制远程会话，镜像将以仅查看模式打开；它的密钥不会更改远程会话。按 **Ctrl-T** 或单击状态行来控制，分离另一个终端，或使用 `borg mirror MACHINE:SESSION --take` 启动时进行控制。取得控制权后，第一键唤醒休眠的远程屏幕；随后的按键和鼠标输入会到达它。落后的查看者会收到当前屏幕，而不是旧的动画帧。在 Borg 的主 Bash、Zsh 或 Fish shell 中输入 `exit` 时会要求确认。 **否** 默认情况下选择并保持相同的 shell、变量、目录和镜像运行。在远程控制台中，`exit` 会询问是否关闭主机上的 shell；选择“是”之后，可用 Alt-H 再次选择该会话以打开新的 shell。

要连接，请按F1，然后按C（或F9→远程→将此Borg共享为主机...）。 Borg 显示粘贴到计算机上终端的两个命令：一个启动已连接到此 borg 的 Claude Code，另一个在每个会话的 Claude Code中保持连接。 Tab 选择一个，Enter 通过终端将其复制到计算机的剪贴板，该终端通过 SSH 在 iTerm2、Ghostty、kitty、WezTerm 和 Alacritty（在 tmux 中，使用 `set -g set-clipboard on`）。在终端不接受它的地方，如在许多浏览器终端中，F3将命令单独显示为纯文本，鼠标可以自由选择它；任意键返回borg。通过 SSH，borg 填写您进来的地址；如果您的计算机通过其他名称（例如 SSH 别名或通过跳转主机）到达服务器，请改为键入该名称。 SSH 必须在没有密码提示的情况下登录：密钥或 SSH 代理。 `borg mcp setup prod` 从命令行打印Claude Code 和 Claude Desktop 相同的内容。

连接后，代理可以看到您所看到的内容：屏幕本身为文本，无论您是在面板还是控制台中，两个面板，突出显示和标记的文件，命令行运行的位置以及在那里键入的内容。它将地点命名为位置：绝对路径或 `~/…` 在机器 borg 上运行， `docker://web/etc/nginx` 容器内，或相对于活动面板的路径。无需询问，它就会读取文件夹、文件（按行范围或包含某些文本的行）、最繁忙的进程和容器，并在其他面板中显示文件或文件夹。

任何改变机器的东西都会在一个显示所有内容的对话框中等待您：命令及其运行位置、新文件或作为差异进行编辑。长的可以使用箭头键、PgUp 和 PgDn 或鼠标滚轮滚动，并且 F3 全屏显示对话框。选择“否”(No)，直到选择“是”(Yes)；如果在您决定时文件发生更改，则编辑将被拒绝。对于配对的计算机， `approval_mode` 在启用“批准该会话的所有内容”之前询问一次。其徽章始终可见；单击徽章或按 Ctrl+Alt+A 可立即将其关闭。当该配对连接关闭时，它也会关闭。配对批准仍然是分开的。命令被输入到您观看的 shell 中，并且不会出现在其历史记录中：本机上的命令会输入到 borg 自己的控制台中，该控制台会在它们运行时显示，因此您可以回答诸如 sudo 之类的提示；将容器中的命令发送到 Docker 视图中该容器的 shell 中。 shell 在命令之间保留其文件夹和变量。

代理还可以键入文本供您查看：提示符处的命令，或在控制台中打开的 vim 或 nano 中的脚本。没有任何内容运行：没有按下 Enter，多行文本以粘贴形式输入，shell 和编辑器无需运行即可插入。

代理还可以像内存搜索那样搜索进程的内存：字符串、指标、文本或字节。内存中可能有密码、密钥和私人消息，而搜索找到的内容会发送给代理，因此对每个进程的第一次搜索都会在对话框中等待您确认，对话框会列出该进程、它的程序和这次搜索。批准后，代理可以再次搜索该进程，直到 borg 退出。它可以请求以管理员身份读取，这会打开系统自己的密码提示。

### Borg云

Borg云让Claude到达borg它没有SSH路由：您在浏览器终端中打开的服务器、容器、NAT后面的机器。双方都连接到一个中继服务器，然后中继服务器将它们连接起来。

1. 在服务器上的borg中，按F1，然后按C。第一个选择是 `borg pair` 有链接； Enter 复制它。该链接有效一次，持续十分钟。它下面是中继：将另一个中继的地址粘贴到那里，然后按Enter保存它并通过它获取链接。
2. 在计算机上的终端中运行它，其中也安装了 borg。它打印一个配对代码：六个表情符号，每个表情符号都有它的名称，例如 `🐱 Cat · 🦁 Lion · 🐎 Horse`.
3. 服务器上的Borg询问是否配对，显示计算机名称和代码。如果代码匹配，请选择“是”。 `borg pair` 然后提议将服务器添加到Claude Code 中，如下所示    `claude mcp add borg-NAME -- borg mcp remote NAME`.

该代码来自两个博格刚刚完成的加密握手，因此仅当您的计算机是与服务器通信的计算机时，两个屏幕上的代码才相同。获得该链接并首先使用它的人会向服务器显示不同的代码，并且无法选择与您的代码匹配的代码。当终端绘制的表情符号比 borg 更窄时，borg 仅显示名称；比较名字。

从那时起，每当那里打开时，Claude都会到达borg。 `borg pair` 单独列出配对的服务器，并且 `borg pair --forget NAME` 忘记了一个；在服务器上，远程访问对话框中的F8会忘记每台配对的计算机。通过borg云Claude也得到 `download` 和 `upload`，在服务器和您的计算机之间复制文件； `borg get NAME:PATH [TO]` 和 `borg put FROM NAME:PATH` 从您的终端执行相同的操作。上传等待您在borg批准。每个批准都会对提出请求的计算机进行命名。

连接是端到端加密的。每个borg在其状态文件夹中保存一个私钥，只有您可读。配对交换公钥，并且每个连接都通过绑定到它们的 Noise IK 握手打开，因此中继仅转发密文，并且不能以任何一个 borg 的名义进行应答。来自另一台计算机的调用无需询问即可读取，就像本地调用一样；选项→插件→“在另一台计算机读取之前询问”使这些读取也等待批准。 Borg 除非已配对或显示配对链接，否则不会与中继保持连接，并且当选项 → 插件中的 borg 云关闭时，根本不会连接。

Borg 将中继服务器保存在配置中，如下所示 `relay = "wss://relay.example.com"`。计算机通过其配对的中继到达服务器；服务器更改中继后，重新与计算机配对。一台机器上的博格共享一个密钥，因此只有第一个打开的博格才能连接到中继；其他人说哪一个有borg云。

当代理连接时， **◈ 远程** 位于快捷方式行的开头；单击它可查看其所做操作的日志：它查看、阅读、显示和键入的内容，以及每个命令和更改、批准或拒绝。 Borg 仅将日志保留在内存中，直到退出；要完全不保留日志，请在“选项”→“插件”中将其关闭。

### 运行中继

`borg-relay` 是博格斯相会的中继。在域指向它的 Linux 服务器上，端口 443 可用，一条命令将其安装为具有 Let's Encrypt 的 TLS 证书的服务：

```sh
curl -fsSL https://raw.githubusercontent.com/0xcd21h/borg-commander/main/scripts/install-relay.sh | sudo sh -s -- relay.example.com you@example.com
```

再次运行以更新。

在 Dokploy、Coolify 或代理添加了 TLS 的其他 Docker 主机上，运行该映像 `ghcr.io/0xcd21h/borg-relay:latest` 并在端口 8080 上为其指定一个域：在 Dokploy 中，来自该 Docker 映像的应用程序在容器端口 8080 上有一个域并且启用了 HTTPS；在 Coolify 中，来自该 Docker 映像的资源，暴露了端口 8080 和一个域。要么也需要 [包装/中继/docker-compose.yml](../../../packaging/relay/docker-compose.yml) 作为撰写服务。图像运行 `borg-relay --behind-proxy`：代理提供 HTTPS 服务并传递 WebSocket，中继通过代理报告的客户端地址计算其限制 `X-Forwarded-For`。它以非特权用户身份运行并进行健康检查（`GET /health`).

在没有此类代理的 Docker 主机上，相同的映像本身服务于 TLS：

```sh
docker run -d --restart unless-stopped -p 443:443 -v borg-relay:/data ghcr.io/0xcd21h/borg-relay --domain relay.example.com --cache /data
```

在另一个添加 TLS 的代理后面，运行 `borg-relay --behind-proxy --listen 127.0.0.1:8080`;仅在代理后面使用它，因为中继信任代理报告的客户端地址。中继对每个地址、服务器和会话、帧大小、带宽、每个会话的字节数、空闲时间和会话长度进行限制。它只存储它的证书。

中继日志仅计数：每分钟一次，当它们更改时，诸如

```text
stats: connections=3 servers=2 sessions=1 joined=14 carried=3.2MiB limited=0
```

通过它所持有的连接，服务器注册并打开会话，并且自启动以来，会话加入，它们携带的字节以及限制拒绝或结束的连接和会话。为了调试， `--log`，或环境变量 `BORG_RELAY_LOG=1` 对于图像，还通过其密钥的开头记录每个服务器的注册、每个会话及其携带的字节以及客户端地址达到的每个限制。

## 查找、任务和查看者

Ctrl-S 打开快速查找。输入一个名称或 glob，例如 `*.rs`;向下和向上在匹配项之间移动，插入标记匹配项，Ctrl-A标记所有匹配项，Enter或Esc关闭搜索。匹配不区分大小写，除非查询包含大写字母。

F5、F6和F8开始复制、移动和删除作业。 Alt-J 打开作业列表以暂停或取消。

复制对话框有一个可选的 **优化硬盘复制** 复选框。使用 Tab 将其聚焦并使用空格键进行切换，或单击它。每个副本开始时都是未经检查的。此模式将小文件批量读取到内存中，然后每批写入，这可以减少在一个硬盘内复制时的源/目标查找。批次最多可容纳 64 MiB 文件数据或 4,096 个文件；通常大于 1 MiB 的文件流。性能取决于驱动器、文件系统和操作系统缓存；不同驱动器之间的速度可能会较慢。对于名称冲突： `o` 覆盖， `s` 跳过， `k` 两者都保留， `a` 覆盖所有， `n` 跳过所有，并且 Esc 取消。副本将写入临时文件并在完成后重命名。

F3 打开查看器。在文本文件、箭头和 PgUp/PgDn 滚动中， `w` 改变包装，并且 Esc 或 `q` 关闭。在图像中，左/右或 `p`/`n` 选择上一张或下一张图像。可用时使用图像协议；其他终端显示色块。

Ctrl-Q 在另一个面板中显示快速预览。 Tab 聚焦；箭头、PgUp/PgDn、Home/End 和鼠标滚轮滚动文档。 Tab或Esc返回文件列表。 Ctrl-L 显示文件信息。 F3 将文本预览扩展到查看器中；关闭它会返回到预览，并保留您的位置、换行和源模式。两者都使用相同的有界文件读取器，因此打开一个大文本文件会读取第一页附近的内容，而不是加载整个文件。

两种文本查看器都突出显示常见的编程语言、标记和配置文件，包括 Rust、Python、JavaScript、TypeScript/TSX、Go、C/C++、Java、C#、Ruby、PHP、Lua、SQL、HTML/CSS、JSON、YAML、TOML、shell 脚本和 Dockerfile。 Markdown 默认打开格式。按 `s` 或在任一查看器中按 F4 来切换源视图。支持标题、强调、列表、任务、链接、表格和围栏代码块。大于 2 MiB 的 Markdown 文件作为源打开以保持内存有限。

F4 在 Borg 编辑器中打开所选文件，Shift-F4 则用 `$VISUAL` 或 `$EDITOR` 打开。编辑器会保留文件的换行符和缩进，像查看器一样高亮代码并显示行号。按住 Shift 配合方向键可选择；Ctrl-C、Ctrl-X 和 Ctrl-V 通过 Borg 的剪贴板复制、剪切和粘贴，从终端粘贴的内容会原样插入。Ctrl-Z 和 Ctrl-Y 撤销和重做，Tab 和 Shift-Tab 增加和减少缩进。F2 或 Ctrl-S 通过临时文件保存，因此文件绝不会只写了一半。不是 UTF-8 文本或大于 32 MiB 的文件会改在查看器中打开。

编辑器会在文本上方的对话框中询问：Tab 在字段和按钮之间移动，Enter 确认所选项，Esc 取消，单击任何一项也有效。Ctrl-F 或 F7 查找，之后 F3 再次查找，Shift-F3 向后查找。Ctrl-R 或 F4 替换：Enter 替换当前匹配并跳到下一个，**跳过** 保留它，Alt-A 或 **全部** 一步替换所有匹配，Ctrl-Z 可以撤销这一步。用小写字母搜索时不区分大小写。Ctrl-G 跳到指定行。Esc 关闭编辑器，若有未保存的更改会先询问是保存还是放弃；如果文件在打开后已在磁盘上更改，会询问是覆盖还是重新载入。单击放置光标，拖动或按住 Shift 单击进行选择，双击选择一个单词，滚轮滚动文本；状态行中的按键也可以单击。

## 配置

通过 **F9 → 选项 → 语言** 切换界面语言。选择英语、简体中文、葡萄牙语（葡萄牙）、西班牙语或俄语后，按 Enter 保存；Esc 取消。设置保存在 `config.toml` 中，取值为 `language = "en"`、`"zh-CN"`、`"pt"`、`"es"` 或 `"ru"`。`BORG_LANGUAGE` 优先于已保存的设置；两者都未设置时，Borg 依次读取 `LC_ALL`、`LC_MESSAGES` 和 `LANG`，不支持的语言回退到英语。命令、路径、文件名和快捷键保持原样。网站语言菜单独立控制指南的语言。

设置保存在 `~/.config/borg-commander/config.toml`，或选择的目录 `$XDG_CONFIG_HOME` 或 `$BORG_CONFIG_DIR`。 F9 → 选项 → 设置打开复选框；空格或单击可切换设置并立即保存。 Esc 关闭窗口。

```toml
theme = "neon"              # midnight, aurora, neon, classic, paper, ember, or your own
icon-style = "auto"         # auto, nerd, or portable; Ghostty gets rich icons automatically
icon-spacing = 1            # spaces after an icon, 1 to 3
status-line = true
menu-bar = false            # keep the menu bar visible
show-hidden = false
return-to-panels = true    # return after commands launched from the panels
restore-terminal = false    # bring back the shell scrollback on the next start
screensaver = true          # a spinning cube or a glitching logo, picked at random
screensaver-after = 300     # seconds of idle time
update-check = true         # look for a new release once a day
graphics = "auto"           # auto, kitty, sixel, iterm or off
relay = "wss://relay.example.com"  # the relay for borg cloud

[plugins]
git = true
system = true
docker = true
docker-console = true       # the command line follows container panels into the container
agent-log = true            # log what Claude does while Borg runs
agent-cloud = true          # paired computers reach this borg through borg cloud
agent-ask-reads = false     # reads from another computer wait for approval

[search]
exclude = ["*.min.js", "fixtures/large"]  # paths below the search folder, as in .gitignore
artifacts = true            # leave out node_modules, Cargo's target and cache-tagged folders
ignore-files = true         # follow .gitignore, .ignore, .rgignore and .borgignore
history = true              # remember searches for Ctrl-P and Ctrl-N

[index]
roots = ["~/Projects"]      # folders indexed for instant search
refresh-minutes = 15        # rebuild an index once it is this old
```

在本地真彩色终端上，Borg 打开并显示其徽标的简短故障介绍；任何键或单击都会跳过它。通过 SSH 和在没有真彩色的终端上，它直接在面板中启动。

面板文件夹、光标位置、分割、列表模式和排序保存在 `~/.local/state/borg-commander`，或选择的位置 `$XDG_STATE_HOME` 或 `$BORG_STATE_DIR`.

当它运行时，Borg将从容器中复制出来的 shell 集成脚本和文件保存在 `$XDG_RUNTIME_DIR/borg-commander`, 或 `borg-commander-<uid>` 在临时文件夹中。只有你可以打开它；其他人制作的或其他人可以输入的名称会被忽略以换取新名称。其 `TTL` 文件从其使用前的时间开始：每个运行的 borg 每小时都会将该时间提前一天，因此一旦过去，该文件夹就可以被删除。

自定义主题进去 `~/.config/borg-commander/themes/`。主题可以扩展内置主题：

```toml
name = "Deep Space"
extends = "neon"

[styles]
cursor = { fg = "#0b0b16", bg = "#00e5ff", bold = true }
dir = { fg = "#b388ff", bold = true }
```

如需构建、测试或贡献，请参阅 [发展](../../../DEVELOPMENT.md).

## 活动和记忆

**Alt-M** 或 **命令→活动监视器** 打开进程监视器。捆绑的系统插件默认启用，可以在选项 → 插件中禁用。进程列表占据活动窗格，所选进程的内存概览位于其对面。 **Enter** 或者双击在监视器上方的窗口中打开该进程：一侧是其内存映射，另一侧是所选区域字节的预览。 **Esc** 关闭它。 **Tab** 切换焦点。 **Alt-W** 或 **[+]** 按钮最大化聚焦窗格； **[=]** 恢复分裂，并且 **[-]** 隐藏显示器。当监视器打开时，采样每秒运行一次；关闭它会停止采样。内存检查暂时保留采样，直到结果到达。

该列表显示CPU、驻留内存、内存增长和磁盘读/写速率。 CPU 100% 表示一个繁忙的核心。共享驻留页面可以出现在多个进程中，因此进程 RAM 值不得添加为唯一的系统总数。在第二个观察到达之前，第一个 CPU 和 I/O 速率样本不可用。

| 钥匙 | 行动 |
| --- | --- |
| Enter | 打开进程内存映射/聚焦区域预览 |
| `/` | 按名称或PID过滤； ↑↓ 仍然移动，Enter 保留过滤器，Esc 清除过滤器 |
| C/M/G/N/P | 按CPU / RAM / 成长 / 姓名 / PID 排序；重复以反转 |
| 输入/输出 | 按读/写速率排序 |
| 时间 | 切换进程树 |
| 空间 | 暂停或恢复采样 |
| 右 | 刷新当前视图 |
| Esc | 背部；从进程列表中关闭 |

单击流程标题进行排序；双击进程以打开其内存映射。概览显示当前常驻内存、观察到的峰值内存、自监控开始以来的变化、CPU、虚拟地址空间以及最近 60 秒常驻内存的图表。一旦读取内存映射并且平台报告它们，就会显示占用空间、交换、私有和共享总计。 **Enter** 在内存窗格中打开其内存映射。内存映射是根据请求进行的测量。进程更改其映射后，使用 R 刷新它。

该地图分为三列：

- **内存占用** 是该进程单独占用的内存：已写入的页面加上换出或压缩的页面。这是要监视泄漏的数字，在macOS上它与 Activity Monitor 的相匹配 *内存* 列。
- **驻留** 现在页面在RAM中，包括与其他进程共享的页面。
- **映射** 是地址空间，包括保留空间。它不是RAM。

一个进程可以映射千兆字节，主要是与其他进程共享的系统库，而其占用空间只有几兆字节。区域开始按用途分组：堆和分配、线程堆栈、程序自己的代码和数据、共享库、映射文件、共享内存、系统和其他分配以及保留范围和保护。团体及其成员按内存占用排序，最后预订。库和映射文件每个文件列出一行；展开文件以查看其区域。组名称是从操作系统的标签推断出来的。选择一个组或文件会对其进行解释并显示其占用空间份额及其最大成员。 Enter 或向右展开组或文件；向左折叠它，或所选行周围的折叠。 G 在分组列表和原始列表之间切换。

**1 内存** 和 **2 打开文件** 切换检查选项卡，或单击其标签。打开文件列表包括描述符、访问模式、类型和路径或端点；另一个窗格显示完整的详细信息、文件大小和当前偏移量（如果可用）。在macOS上，它还包括诸如 `cwd` （当前目录）和 `txt` （映射的可执行文件）。 R 刷新列表。切换选项卡保留列表位置。访问限制提供现有的显式管理员重试。普通文件还会在详细信息下方显示其内容，与快速查看相同：**Tab** 将焦点移到预览以便滚动，**F3** 在查看器中打开该文件。Borg 以您自己的权限按路径读取文件，而不是通过进程的描述符。

选择一个可读区域会自动在对面的窗格中捕获其中最多 64 KiB 的内容。如果区域开头全是零，捕获会继续读取到第一个含有数据的页，字节上方的一行会显示该窗口位于区域中的位置。快速移动会稍作延迟后合并；选择另一个区域会清除旧的预览并取消其待处理的读取。不可读的区域会显示消息而不尝试读取。按 **Tab** 或 **Enter** 滚动预览。在那里按 **Esc** 会把焦点移回列表；在地图中按 **Esc** 会返回进程列表，并保留其光标和过滤器。

连续的全零行会折叠为一行，例如“· 60K 个零字节 ·”。**]** 和 **[** 跳到下一个和上一个数据块，**>** 和 **<** 捕获区域中下一个和上一个 64 KiB。**H** 切换十六进制/文本表示，**R** 再次捕获所显示的窗口，**D** 突出显示与同一进程和地址的上一次捕获之间的差异。文本表示显示可打印的 ASCII 并用点代替其他字节。快照是实时观察；该过程不会暂停，因此捕获不是其整个状态的原子图像。除非明确导出，否则它们会保留在内存中。**E** 使用新的文件名和仅限所有者的文件权限将原始字节导出到活动文件面板的目录中。现有文件永远不会被覆盖。

**M** 在字节和区域的页面图之间切换预览：每个 4 KiB 页面一个单元格，大区域中则每一段连续页面一个单元格，并按其内容标记：指向进程自身内存的指针、文本、UTF-16 文本、代码、压缩或加密数据、其他数据、填充、零，以及不在内存中的页面。图例给出每类内容在区域中所占的比例。在获得焦点的页面图中，方向键、**PgUp**、**PgDn**、**Home** 和 **End** 移动光标，**Enter** 以字节形式打开光标下的页面。超过 16,384 页的区域会被均匀抽样。在 Linux 上，页面图会向系统询问哪些页面在内存中，其余页面不读取，因此既不会换回已换出的页面，也不会触碰新页面；在 macOS 上，未触碰的页面读作零。类别仅根据字节推断，请把它们当作参考，而不是定论。

按 **/** 在内存窗格中，或 **Ctrl-F** 从任一窗格中搜索内存。选择模式、大小写匹配以及可读进程内存或当前快照。 **文字** 搜索 UTF-8、UTF-16（两种字节顺序）和 UTF-32（两种字节顺序）。 **统一码** 还规范兼容性字符和组合序列：例如， `𝐁𝐨𝐫𝐠` 比赛 `Borg`。这并不等同于仅仅看起来相似的不相关字母。 **十六进制** 接受字节对，例如 `42 6F 72 67`.

**字符串**和**指标**只读取进程自己填写的内存：没有文件支持的内存，以及进程可以写入的内存；在 macOS 上，进程从未写入过的区域也会被跳过。**字符串**将每一段至少六个可打印 ASCII 或 UTF-16LE 字符的连续内容只列出一次，并给出它在内存中的副本数，同时跳过重复字符或标点之类的填充内容；如果给出查询，则只保留包含它的字符串。**指标**保留看起来像 URL、IP 地址、电子邮件地址、文件路径、命令行、机密（私钥、访问令牌或密码赋值）或一长段 base64 的字符串，并为每一项标注类别。

Borg 还会读取进程已映射文件中的字符串，最多 1 GiB，并用 • 标记只存在于内存中的字符串：即进程自己构建、接收或解码的文本，而不是从其文件中加载的文本。指标排在最前，只在内存中的字符串排在其文件中也有的字符串之前，读起来像单词的字符串排在其余字符串之前。列表保留最好的 2,000 个。每一行在其他匹配显示所在区域的位置显示类别和副本数，预览则在原处显示该字符串；**C** 依次跳到它的各个副本。这些结果只是值得细看的线索，并不能证明什么：普通程序中也有大量 URL、路径和密钥。

在内存映射或搜索匹配中按 **I**，可检查进程运行的是否是其文件中的代码。它会将内存中的代码与映射来源的文件进行比较并报告不同的页，在没有文件支撑的内存中搜索可执行映像（ELF、Mach-O 和 PE）的文件头，并列出没有文件支撑的可执行内存、同时可写可执行的内存，以及来自已删除、无名称或临时文件的代码。它还会检查整个进程：通过 `LD_PRELOAD`、`LD_AUDIT`、`DYLD_INSERT_LIBRARIES` 或 `/etc/ld.so.preload` 注入的库、库搜索路径、Linux 上的跟踪者、文件已消失或被替换的程序，以及与其程序名称不同的进程名。

检查结果占据列表窗格，先列出警报，然后是警告和提示。选中一项会预览它所涉及的字节并突出显示证据，列表下方的行说明还有哪些原因可能导致它。在运行时编译代码的程序，例如浏览器、Java 和 JavaScript 引擎，始终持有没有文件支撑的代码，因此对它们来说这些结果只是提示。**R** 重新检查，**Ctrl-C** 停止检查并保留已发现的结果，**Esc** 返回。一次检查最多读取 512 MiB 代码和 1 GiB 其他内存，最长 45 秒，并会说明是否提前停止。

在 Linux 上，页表会说明进程更改了哪些代码页，因此只读取这些页；在 macOS 上，没有脏页的区域也不会被读取。macOS 共享缓存中的代码没有自己的文件，因此不进行比较。检查无法读取的内存会被计入，并提供 **A: 管理员**。检查结果只是线索，而不是结论：调试器、性能分析器、更新程序和安全工具也会留下同样的痕迹。

匹配占据列表窗格并显示其原始地址、编码和区域。选择匹配项会在相反的窗格中预览其周围的字节，并突出显示匹配的字节。 Enter 聚焦预览； Esc 将焦点返回到比赛。匹配中的Esc恢复之前的地图或进程列表。搜索存储的快照使用其捕获的字节，而不读取正在运行的进程。进程搜索以块的形式读取，报告无法访问的字节，并在 2,000 个匹配项或 60 秒后停止。 **N** 从该位置继续； **Ctrl-C** 停止，同时保留结果。覆盖率报告区分搜索到的字节和不可访问的字节。进程在被搜索时可以更改其内存。

受限的内存映射或快照读取以及部分无法访问的搜索，提供 **A：管理员**。在macOS上，这将打开系统授权提示；在 Linux 上它使用 `pkexec` 并需要可用的授权代理。只有一个短暂的检查助手被提升。 Borg 保持正常运行，助手仅返回地图数据或有界字节。 macOS 不允许任何其他程序（包括管理员）读取其自身程序（系统完整性保护）以及使用强化运行时（Hardened Runtime）构建的程序的内存。Borg 从程序的签名中读出这一点：进程详情显示 **内存受保护**，被拒绝的读取会说明原因，并且不提供 **A：管理员**，因为它无济于事。这些进程的内存映射和打开的文件仍会显示。Borg 已以管理员身份运行时也不提供该选项。Linux 安全策略仍可能拒绝访问；Borg 显示故障并使普通进程监视器可用。

进程标识包括其启动时间，因此重用的PID不会继承另一个进程的历史记录。内存映射、检查输出、快照和历史记录都是有限的。 Borg Commander 在右下角保持可见，包括控制台、查看器、监视器、对话框和屏幕保护程序。
