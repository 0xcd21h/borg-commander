## 安装

可以从 [GitHub Releases](https://github.com/0xcd21h/borg-commander/releases) 下载二进制文件，也可以运行安装脚本。安装脚本支持 macOS 和 Linux，Intel 与 ARM 架构均可：

```sh
curl -fsSL https://raw.githubusercontent.com/0xcd21h/borg-commander/main/scripts/install.sh | sh
```

安装脚本会校验压缩包的校验和，并把 `borg` 放到 PATH 中的某个文件夹里，因此在同一个终端中就能直接运行。如果 `~/.local/bin` 已在 PATH 中，就选用它；否则，如果 `/usr/local/bin` 可写（例如在容器中以 root 身份运行），就选用它；都不满足时，则使用 `~/.local/bin`，并将其添加到 Shell 的启动文件中。安装完成后会自动启动 borg；设置 `BORG_NO_RUN=1` 可跳过这一步，设置 `BORG_INSTALL_DIR` 可指定安装文件夹。如果已经安装了相同版本，再次运行安装脚本时会跳过下载。

从源码构建需要 Rust 1.97 或更高版本：

```sh
cargo install --locked --git https://github.com/0xcd21h/borg-commander borg-app
```

Homebrew 支持已经就绪，tap 发布后即可使用：

```sh
brew install 0xcd21h/tap/borg-commander
```

在要浏览的文件夹中运行 `borg`。按 F10 退出，按 Ctrl-O 从控制台切回面板。如果是下载安装的，运行 `borg update` 即可更新；如果是通过 Homebrew 或 cargo 安装的，请用相应的工具更新。`borg --version` 会显示已安装的版本。

## 主题与图标

在 F9 → 选项 → 主题 中选择主题。[主题一览](../../../README.md#themes) 展示了全部六款主题：Midnight、Aurora、Neon、Classic、Paper 和 Ember。

主题使用固定的颜色，因此自定义的终端调色板不会影响主题的外观。不支持真彩色的终端会使用 256 色调色板中最接近的颜色。

每个文件都有图标。在 Ghostty 中，Borg 会自动使用更丰富的 Nerd Font 图标；其他终端默认使用通用符号：`/` 表示文件夹，`@` 表示链接，`*` 表示可执行文件。如果其他终端配置了合适的字体，可以设置 `icon-style = "nerd"` 来使用丰富图标；设置 `icon-style = "portable"` 则始终使用通用符号。默认值 `"auto"` 会根据终端自动适配，且不会把检测结果保存为你的字体偏好。

发布压缩包中附带 **Borg Mono**，这是一款内置 Nerd Font 图标的等宽字体。从 `fonts/` 安装它的常规和粗体字形，在终端设置中选择 Borg Mono，然后选择 `"nerd"` 图标样式。Borg 无法替你更改终端字体。安装脚本会把字体放在 `${XDG_DATA_HOME:-~/.local/share}/borg-commander/fonts`；Homebrew 则放在 `$(brew --prefix)/share/borg-commander/fonts`。

## 集合与递归搜索

“搜索”菜单中提供集合以及按文件名或内容的递归搜索。两者都以可排序列表的形式显示结果，并列出每个文件的源路径，也都支持查看器和快速预览。

- **Ctrl-F：** 搜索当前文件夹及其下的所有内容。所有词都必须匹配：`main rs` 能找到 `main.rs`，`a | b` 则匹配其中任意一个词。全小写的词不区分大小写；含大写字母的词则严格区分大小写。还可以使用 `*.log` 这样的 glob 通配符、带引号的短语、带斜杠的路径（如 `src/lib`），以及用 `-word` 排除匹配项；此外还支持以下筛选条件：`ext:rs,toml`、`type:file`、`type:dir`、`type:link`、`size:>10M`、`size:1M..50M`、`mod:<7d`（最近一周内修改过）、`mod:>1y` 和 `in:src`（路径中任意位置的文件夹）。最近的搜索会列在表单下方，在同一文件夹中进行的搜索排在前面；点击其中一条，或在查询框中按 Ctrl-P 和 Ctrl-N，即可再次使用。无论 glob 写成大写还是小写，任何文字的文件名都能正确匹配；无论文件系统如何存储带重音的字母，也都能正确匹配。靠近搜索文件夹的匹配项会最先显示，此时目录树的其余部分仍在读取中。
- **Alt-K：** 把已标记的文件（或当前文件）收入另一个面板中的集合。集合中保存的是引用，不会复制文件内容。
- **Alt-V：** 从可滚动列表中选择已保存的集合，列表会显示每个集合的条目数和估算大小。按 F7 或 N 新建集合。重启 Borg 后集合仍会保留。
- **Esc：** 隐藏结果，同时保留光标、滚动位置、标记、筛选和分组。
- **Alt-Shift-R：** 重新显示已隐藏的结果。结果被隐藏时，扫描仍会继续进行。
- **Alt-D：** 打开“文件夹大小”，按总大小或文件数量查找文件夹。默认包含隐藏文件。Alt-D 会打开 Ctrl-F 对话框，并设为 *文件夹总计*；更改 *查找对象* 即可在两种模式之间切换。按 Ctrl-C 停止扫描。
- **Alt-S：** 计算所选文件夹的大小。**Alt-Shift-D：** 打开当前文件夹的大小树。
- **Alt-W：** 最大化或还原当前结果窗格。结果默认在普通窗格中打开。标题栏中的 `[+]`（最大化）、`[=]`（还原）和 `[-]`（折叠）按钮都可以点击。折叠会隐藏视图；按 Alt-Shift-R 可将其恢复，布局和选择保持不变。
- **Ctrl-S：** 按名称或源路径筛选结果。筛选条件为空时显示全部结果。

### 在文件内容中搜索

在 Ctrl-F 对话框的 **包含文本** 中输入文字，即可列出该文件夹下包含这段文字的文件。名称模式仍然有效，因此 `*.rs` 加上 **包含文本** 中的 `fn main`，会找到含有它的 Rust 文件。字段旁的开关与查找栏中的相同：Alt-C 精确匹配大小写（否则全小写的查询不区分大小写），Alt-W 匹配整个单词，Alt-R 把文字当作正则表达式。这些开关也可以点击。在该字段中按 Ctrl-P 和 Ctrl-N，可以调出查找栏中最近的查询和之前搜索过的文字。按文本搜索只列出文件，因此不能与文件夹总计或最小文件数一起使用，**文件夹大小** 中也没有 **包含文本** 字段。

每个结果都会在 **匹配** 列中显示第一处匹配所在的行及其行号，状态行也会在文件路径后加上行号。按 F3 会在查看器中打开该文件并定位到这处匹配，查找栏已按该查询打开，按 Enter 即可跳到下一处；按 Ctrl-Q 则会在快速预览中显示这处匹配，并标出查询。Markdown 和 JSON 文件在两者中都会以源码形式打开，因为搜索读取的是文件原本的内容；按 `s` 可切换到格式化视图。按 F4 会在 Borg 的编辑器中打开该文件并定位到这处匹配，匹配已选中，查找栏也已按该查询打开；Alt-E 则在另一个面板中这样打开，让搜索结果保持可见。Borg 在后台读取文件，上下文行会统计已读取的文件数。二进制文件（前 8 KiB 中含有 NUL 字节）和超过 64 MiB 的文件不会被读取，并计为二进制或过大。按 Ctrl-C 可停止搜索；与其他搜索一样，最多找到 20,000 个文件。

### 处理搜索结果

点击列标题可按该列排序，再次点击则反转顺序。“左侧”和“右侧”菜单中也提供排序选项，“搜索”菜单还增加了按源文件夹排序以及按文件夹或文件类型分组的功能。在分组标题上按 Enter 可折叠该组；按 Insert 可标记组中匹配的文件。排序或筛选时标记会保留，页脚还会统计被筛选条件隐藏的已标记文件。

F3 和 Ctrl-Q 打开原始文件；按文本搜索后，两者都会定位到文件中的第一处匹配。快速预览会随光标在结果中移动，在每个文件的匹配处显示，并像查找栏那样标出查询。Alt-E 在另一个面板中用 Borg 的编辑器打开文件，让搜索结果保持可见。Esc 或 F10 关闭这个编辑器，焦点回到搜索结果；如果之前开着快速预览，它也会重新出现。F5 复制到真实文件夹；如果另一个面板是集合，F5 则会向集合添加引用。F6 的目标必须是真实文件夹。在集合中，F8 只移除引用，不会动文件本身；在搜索结果中，F8 会询问是否删除原始文件。在集合中按 Shift-F8 也可以删除原始文件，但需要先确认。如果同时标记了某个文件夹和其中的文件，任务只会处理该文件夹一次。**定位原文件** 会在另一个面板中打开文件所在的文件夹。按 Left 或 Esc 隐藏结果，按 Alt-Shift-R 可在原来的位置恢复。即使 Shell 中有未完成的命令，Tab 也能在面板之间切换。Shell 始终位于一个真实的文件夹中。按 F10 退出前总会先询问。

Git 和压缩包操作目前只能在真实文件夹面板中使用。要对集合中的文件执行这些操作，请先用 **定位原文件** 打开它所在的文件夹。

### 搜索限制

搜索在可取消的后台工作线程中读取文件名和元数据，找到 20,000 个匹配项后停止。上下文行会显示搜索是否已完成、出现的错误和跳过的条目，以及是否达到该上限。只有开启 **显示隐藏文件** 时才会搜索隐藏文件夹。搜索不会离开起始位置所在的文件系统，也不会跟随指向文件夹的符号链接。搜索窗口可以将结果限定为文件或文件夹，并设置最小大小。

### 文件夹总计与大小树

选择 **文件夹总计** 后，Borg 会先统计每个文件夹下的所有文件，再按名称、大小或最少文件数进行筛选。Borg 保留最大的 20,000 个匹配文件夹，并按大小排序；点击“文件”列可改为按文件数排序。可以使用 `node_modules` 或 `*cache*` 这样的模式，或用 `*` 查看起始文件夹下的所有文件夹。

总计是文件内容大小之和。删除文件夹后实际释放的磁盘空间可能与之不同。嵌套的文件夹也会计入其父文件夹的总计。符号链接永远不会被跟随，扫描不会离开起始位置所在的文件系统，包含自身的文件夹（通过绑定挂载或硬链接文件夹）只计算一次。如果因为这类边界，或者因为某个子文件夹无法读取或被排除，导致总计不完整，则会以 ≥ 标示。文件夹扫描只读取元数据，从不读取文件内容。测量完成后才会显示结果，你可以随时取消扫描。

**文件夹大小树** 在当前面板中显示起始文件夹及其子文件夹的总大小。Right 展开分支，若分支已展开则进入该分支；Left 折叠分支或选中其上级。Enter 打开文件夹本身。点击分支箭头可折叠或展开分支，点击列标题可将同一层级的文件夹按名称、大小或文件数排序。Esc 隐藏大小树，Alt-Shift-R 可恢复其分支、标记和光标。文件操作作用于真实路径；如果同时标记了某个文件夹和它的子文件夹，复制或删除任务只会处理父文件夹。

### 搜索会排除哪些内容

勾选 **排除构建输出、缓存和被忽略的文件** 时，按名称搜索会跳过生成的文件夹：`node_modules`、`.git`、Python 缓存和虚拟环境、`target` 和 `dist` 等与构建文件（`Cargo.toml`、`package.json`）相邻的文件夹，以及任何带有 `CACHEDIR.TAG` 文件的文件夹。同时还会跳过被 `.gitignore`、`.ignore`、`.rgignore` 或 `.borgignore` 排除的文件，以及 `[search] exclude` 中的 glob 所匹配的内容。

要更改排除的内容，请在搜索对话框中按 F4，或点击 **F4 编辑**。你可以分别开启或关闭对生成文件夹和忽略文件的排除，也可以添加（Ins）、编辑（Enter）或删除（Del）模式。更改会保存到配置文件中。被排除的文件夹如果自身名称匹配，仍会出现在结果中；上下文行会统计被排除的文件夹数量。在查询中加入 `excluded:yes` 可临时搜索全部内容，加入 `hidden:yes` 则会包含隐藏文件。大小扫描始终读取全部内容。

在 macOS 上，从 `~/Library/Containers` 和 `~/Library/Group Containers` 的上层开始的搜索和大小扫描会跳过这两个文件夹：读取其中的内容时，macOS 会挂起读取操作，直到有人回答是否允许访问其他应用的数据。如果搜索是从这两个文件夹内部开始的，则会正常读取。

搜索历史保存在本机，只有你能读取。设置 `history = false`（位于 `[search]` 下）即可停止保存。

### 使用索引即时搜索

**搜索 → 为此文件夹建立索引以便即时搜索** 会为当前文件夹下的所有名称维护一份索引，之后在该文件夹或其任意子文件夹中按 Ctrl-F 都会立即得到结果。上下文行会显示索引的建立时间。Borg 启动后，以及索引超过 15 分钟时，会在后台重建索引；新索引就绪之前，旧索引会继续提供结果。不排除任何内容或使用不同排除规则的搜索会改为直接读取文件夹；按文本搜索也是如此，因为索引中只有名称。再次选择该菜单项可停止索引并删除索引。索引与大小扫描结果一起保存在缓存文件夹中，配置中的 `[index]` 列出了已建立索引的文件夹。

### 在后台计算大小

如果想在测量大小的同时保持普通文件面板打开，请按 **Alt-I** 或选择 **搜索 → 在后台计算大小**。Borg 会扫描当前文件夹下的每个文件夹（包括隐藏文件），每完成一个文件夹就填入其总大小。扫描期间你可以继续浏览或使用控制台。仍在测量的文件夹会显示一个不断增长、标有 `≥` 的总计；离开文件夹再回来时，总计依然保留。面板页脚显示进度；再次按 **Alt-I** 或点击页脚，可停止扫描并保留已测得的总计。开始复制、移动或删除任务时，正在进行的大小扫描会停止。已完成的扫描与大小树和文件夹总计共享缓存。

### 已保存的大小扫描

已完成的扫描会保存在本机。文件夹总计和大小树都会复用针对同一文件夹、采用相同隐藏文件设置所保存的扫描结果。重新打开之前测量过的文件夹时，保存的大小会立即显示并标有 `~`，大小树上方会显示测量日期。在任一大小视图中按 **Ctrl-R** 重新扫描，按 **Ctrl-C** 取消。刷新期间，旧的大小树保持可见；如果新扫描被取消或失败，旧的大小树也会保留。普通文件夹列表中也会显示已保存的总计（如果有）。在 Borg 之外所做的更改可能使这些数据过时，而浏览本身绝不会自动触发递归扫描。Borg 中的复制、移动和删除任务会丢弃涉及其所改动路径的已保存扫描。

本地 SQLite 缓存最多为 16 个起始文件夹保存每个已测量的文件夹。大小树会在你展开分支时才加载其子文件夹。一个分支最多显示 20,000 个文件夹，文件夹总计最多保留最大的 20,000 个匹配项；这些显示上限不会中止扫描，也不会改变总计。“该文件夹中的文件”一行统计的是直接存放在已展开文件夹中的字节数。出错和被跳过的子文件夹会使总计被标记为不完整。缓存位于 `~/.cache/borg-commander`，如果设置了 `XDG_CACHE_HOME`，则位于其下；`BORG_CACHE_DIR` 可覆盖该位置。缓存只保存可以重新生成的测量结果，与集合相互独立。硬链接文件的每条路径都会各计算一次。所有大小衡量的都是文件内容，因此文件在磁盘上实际占用的空间可能更大，也可能更小。

## 按键

两行快捷键栏位于命令行下方。第一行是功能键；第二行是搜索、集合以及其他随当前操作而变化的快捷键。两行都可以点击。通知会临时占用第二行。

| 按键 | 操作 |
| --- | --- |
| Up, Down, PgUp, PgDn, Home, End | 移动 |
| Enter, Right | 打开文件夹 / 运行或查看文件 |
| Left | 返回上级文件夹 |
| Tab | 切换面板，或进入快速预览后再返回文件列表 |
| Ctrl-O | 显示 Shell / 返回面板 |
| Alt-I | 在后台计算文件夹大小 / 停止计算 |
| Ctrl-S | 在文件夹中快速查找 |
| Ctrl-Q | 快速预览：在另一个面板中预览光标所在的文件（文本、图片或文件夹） |
| Ctrl-L | 信息：在另一个面板中显示大小、权限、所有者、日期和可用空间 |
| Insert, Ctrl-T, Shift-Up/Down | 标记文件 |
| `+` `-` `*` | 按模式选择、取消选择或反选（`*.rs`、`build/`） |
| Alt-Enter | 把已标记的文件名（或当前文件名）放到命令行上 |
| Ctrl-Insert / Alt-Shift-Insert | 复制已标记的文件名 / 其完整路径 |
| Shift-Enter, Ctrl-J | 在命令行光标处插入换行；Enter 运行命令，Ctrl-C 清空命令 |
| Alt-A / Alt-Shift-A | 把当前面板 / 另一个面板的文件夹路径放到命令行上 |
| Shift-PgUp / Shift-PgDn | 前后滚动控制台输出 |
| Shift-Home / Shift-End | 跳到最早的控制台输出 / 回到实时提示符 |
| Ctrl-P / Ctrl-N, Ctrl-R | Shell 历史：上一条 / 下一条命令、搜索（由你的 Shell 处理） |
| Alt-. | 显示隐藏文件 |
| Alt-R | 重新加载当前面板：其中的文件夹、搜索结果或集合 |

| F3 | 查看（文本或图片） |
| F4 / Shift-F4 | 在 Borg 编辑器中编辑 / 在 `$VISUAL` 或 `$EDITOR` 中编辑 |
| F5 / F6 | 复制 / 移动到另一个面板 |
| F7 | 新建文件夹 |
| F8 | 删除 |

| F10 | 退出 |

命令行为空时，Tab、Enter、Home、End、Left 和 Right 用于控制面板。一旦开始输入命令，这些键就会交给 Shell 处理。Ctrl-P、Ctrl-N 和 Ctrl-R 使用 Shell 自身的命令历史。Shift-Enter（或 Ctrl-J）插入换行而不运行命令。多行命令（无论是输入的还是从历史中调出的）会让提示符区域变高、面板变矮，从而确保光标始终可见。Shell 常用的编辑和补全快捷键都可以照常使用。

复制的内容会通过终端进入你的计算机的剪贴板，即使通过 SSH 连接或在你控制的镜像中也是如此。Borg 还会记住最近 20 次复制：在 Borg 自己的输入框（例如对话框和内存搜索）中，按 Ctrl-V 或 Shift-Insert 会粘贴最近一次复制的内容，即使终端无法访问你的剪贴板也可以。在命令行上，Ctrl-V 由 Shell 处理，因此请使用终端的粘贴快捷键。对于没有 Insert 键的键盘，“文件”菜单中提供了这两种复制操作。内容过大、无法经由终端传递的复制只会保留在 Borg 中。

如果终端占用了 F 键，可以在 1.5 秒内依次按 **Esc 和一个数字**：Esc 1 到 Esc 9 相当于 F1 到 F9，Esc 0 相当于 F10。例如，Esc 9 打开菜单，Esc 5 执行复制。Borg 等待输入数字时，功能键行会提示该按哪个数字。如果当前打开着某些内容（通知、结果、快速预览或信息），第一次按 Esc 会将其关闭，第二次按 Esc 则取消。如果终端会传递 Alt 键，Alt-1 到 Alt-0 也同样有效。在 macOS 上，可能需要在终端中开启“将 Option 键用作 Meta 键”。

## 鼠标与控制台

单击某一行可将光标移到该行，双击可打开，右键单击可标记。单击菜单栏或快捷键栏即可使用其中的功能。鼠标滚轮可滚动面板。

对话框同样支持鼠标操作。单击列表中的某一行即可选中；在主题和语言选择器、远程主机和远程访问中，再次单击即可确认。滚轮可滚动主题、设置和任务等列表。对话框边框上显示的按键也可以点击：点击 **Esc 关闭** 可关闭对话框，点击按钮可回答问题。在列表、选择器或“关于”窗口之外单击会将其关闭，而表单和询问会一直保持打开，直到你作出回答。

Ctrl-O 在面板和控制台之间切换。在你输入命令或打开控制台之前，Shell 会切换到当前面板所在的文件夹。在 zsh 中，这一过程是静默的，提示符会重新绘制；在 bash 和 fish 中，则会在控制台中看到一条简短的 `cd` 命令。如果控制台是你自己打开的，执行命令或按 Ctrl-C 后它会保持打开。“执行命令后返回面板”仅适用于从面板运行的命令。在 Shell 提示符下，Option-Left 和 Option-Right（Linux 上为 Alt）可按单词移动光标。

在控制台中，鼠标滚轮可向回滚动查看输出，而不会影响正在输入的命令。Shift-PgUp 和 Shift-PgDn 按页滚动，Shift-Home 跳到最早的输出，Shift-End 回到实时提示符，直接输入也会回到实时提示符。要复制屏幕上的输出，请按终端支持的方式选中（通常是按住 Shift 拖动），然后使用终端的常规复制快捷键。

## Git 插件

Git 支持以内置插件的形式提供，默认启用。它的复选框位于 F9 → 选项 → 插件；关闭后会隐藏 Git 菜单和状态列，并停止后台状态检查。需要安装 Git，并确保它位于 PATH 中。

在仓库内，面板会显示当前分支，并在每个文件旁显示两个字符的状态。左边的字符表示索引（已暂存的更改），右边的字符表示工作区。`M` 表示已修改，`A` 表示已添加，`D` 表示已删除，`R` 表示已重命名，`??` 表示未跟踪，`U` 表示有冲突。文件夹会汇总其中的更改。干净的文件和被忽略的文件不显示标记。在仓库之外，这部分空间留给文件名使用。

Git 菜单可显示仓库状态、未暂存和已暂存的差异以及最近的提交，还可以暂存或取消暂存已标记的文件（未标记任何文件时则针对当前文件）。差异和历史记录在常规查看器中打开。取消暂存不会改动工作区中的文件。在切换文件夹、运行命令或执行 Git 操作后，状态会刷新；面板空闲时，每五秒也会刷新一次。Git 菜单中的 **刷新状态** 可立即重新检查。

## Docker 插件

按 **Alt-C** 或选择 **命令 → Docker**，可在当前面板中列出容器，按 Compose 项目分组，不属于任何项目的容器排在最后。另一个面板显示所选容器的信息：状态、端口、网络、挂载、命令和重启策略，以及实时的 CPU、内存、网络和磁盘使用情况，并附有最近一分钟的图表。选中项目时，则显示项目文件夹、其中的容器以及它们的资源使用合计。按 Esc 关闭该视图。

| 按键 | 操作 |
| --- | --- |
| ↑ ↓, PgUp, PgDn, Home, End | 移动 |
| ← → / Enter | 折叠或展开项目；在容器上按 Enter 可跳到其详细信息 |
| S / X / R | 启动 / 停止 / 重启容器或项目中的容器 |
| P | 暂停或恢复 |
| F | 浏览容器中的文件 |
| E, Alt-2 | 在容器中打开 Shell，或返回已打开的 Shell |
| Alt-1 | 重新显示容器概述，在其 Shell 中也可使用 |
| `/` | 按名称、服务、镜像或项目筛选 |
| Tab | 在列表和详细信息之间切换 |
| Alt-W | 最大化当前焦点所在的窗格 |

停止和重启前会先请求确认。对项目执行操作时，只会影响需要改变状态的容器，例如“启动”只会启动已停止的容器。

### 容器文件

在运行中的容器上按 **F**，会关闭 Docker 视图，并在该面板中显示容器的文件系统，从容器的工作目录开始。面板标题会显示容器名称。另一个面板仍停留在主机的文件夹中，因此 **F5** 可以双向复制；**F3** 查看、**F7** 新建文件夹和 **F8** 删除则在容器内执行。搜索、大小统计、预览和编辑仅适用于主机。**Alt-C** 返回 Docker 视图，在容器根目录中选择 `..` 会让面板回到之前显示的主机文件夹。浏览容器需要容器中有 `sh`，因此无法列出没有 Shell 的精简镜像。

当面板显示容器的文件时，命令行会跟随面板：它会变成该容器的 Shell，在面板所在的文件夹中启动，提示符开头显示容器名称。命令在容器内运行，运行结束后面板会刷新，在其中执行 `cd` 也会让面板随之切换。Ctrl-O 显示该容器的控制台，标记为 **▣ 容器名 控制台**。切回主机面板时，命令行和 Ctrl-O 重新归主机使用，之前在那里输入的内容也仍然保留。这与 Docker 视图中容器的 Shell 标签页是同一个 Shell。

如果希望命令行始终留在主机上，请在 选项 → 插件 中关闭 **跟随**。之后，当面板显示容器的文件时，命令行会变暗并标记为 **⌂ 主机**，在切换到主机面板之前按 Enter 不会有任何反应，从而避免命令在错误的机器上运行。

### 容器 Shell

**E** 会在详细信息面板的 Shell 标签页中打开容器内的 Shell（如果镜像中有 bash 就用 bash，否则用 `sh`），并将你的按键（包括功能键）发送给它。**Alt-1** 显示概述，**Alt-C** 返回列表，鼠标滚轮可向回滚动查看 Shell 的输出。在你查看其他容器、关闭 Docker 视图或使用主机控制台时，Shell 会继续运行；其所属容器在列表中标有 `›_`，并计入 Alt-C 快捷键上显示的数量。当你退出 Shell、其容器停止或 Borg 退出时，Shell 会关闭（如果还有打开的 Shell，Borg 会先询问）。

该插件使用 `docker` 命令行工具及其当前上下文，因此同样适用于 Docker Desktop、OrbStack、Colima 和远程引擎。可在 选项 → 插件 中关闭该插件。

## Time Machine 排除项

在 macOS 上，按 **Alt-T** 或选择 **命令 → Time Machine**，可查看 Time Machine 在备份中排除了哪些内容，并进行修改。在面板中，本身被排除的项目会标有 ⊘，页脚会统计其数量，或提示整个文件夹不会被备份。**Ctrl-L** 信息视图会显示 Time Machine 如何处理光标所在的项目。

该窗口有三个标签页；按 **1**、**2**、**3** 或 **Tab**，或直接点击标签页即可切换。**所选项** 列出已标记的项目，或光标所在的项目。**此处的缓存** 会在面板所在文件夹中搜索缓存和构建文件夹，例如 `node_modules`、`target`、`.venv` 以及带有 `CACHEDIR.TAG` 的文件夹，按大小从大到小排列，并统计其中仍有多少内容会被备份。**全部排除项** 按类型列出 Borg 能找到的所有排除项：对项目本身做了标记的排除项（Spotlight 已知的，以及面板所在文件夹中的）、固定路径、被排除的宗卷，以及 macOS 始终排除的位置。

按 **Space**、**Insert** 或右键单击可标记行，按 `*` 反转标记。**E** 通过标记项目本身来排除已标记的行（或光标所在行）：这种方式无需密码，排除状态会随项目一起移动，但如果某个工具删除并重新创建了该文件夹，排除状态就会丢失。**P** 则改为排除路径，无论该路径下是什么内容都会保持排除，此操作会在系统对话框中要求输入密码。**I**、**Delete** 或 **F8** 可重新包含项目。要重新备份某个已排除文件夹中的项目，需要包含该文件夹。macOS 自行排除的内容无法更改。

在“全部排除项”中，按 **A** 可排除你输入的路径，即使该路径目前还不存在。**R** 重新搜索，**Enter** 或在某行上再次单击会在当前面板中显示该项目，**Esc** 关闭窗口。排除或包含宗卷同样需要输入密码。Time Machine 可能需要你的终端在 系统设置 › 隐私与安全性 中拥有完全磁盘访问权限，才能报告它如何处理某些文件夹；在获得权限之前，这些文件夹会显示为“未知”。在其他系统上，该菜单项会隐藏。

## Claude 与其他智能体（MCP）

`borg mcp` 让 Claude 等 AI 智能体在你已打开的 borg 中工作，无论 borg 运行在你自己的机器上，还是运行在你通过 SSH 访问的服务器上。除了 borg 之外无需安装任何东西：智能体会自行启动 `borg mcp`（对于服务器则通过 SSH 启动），然后连接到在那里运行的 borg 会话。服务器无需开放任何端口，也无需访问互联网。

### 连接 Claude

按 F1 再按 C（或选择 F9 → 远程 → 将此 Borg 共享为主机…）。Borg 会显示两条命令，供你粘贴到自己计算机上的终端中：一条会启动已连接到此 borg 的 Claude Code，另一条则把该连接添加到 Claude Code 中，供所有会话使用。按 Tab 选择其中一条，按 Enter 通过终端将其复制到你的计算机的剪贴板。通过 SSH 使用 iTerm2、Ghostty、kitty、WezTerm 和 Alacritty 时均可如此复制（在 tmux 中需添加 `set -g set-clipboard on`）。如果终端不支持（许多浏览器终端都是如此），按 F3 会单独以纯文本显示该命令，方便你用鼠标选中；按任意键返回 borg。

通过 SSH 连接时，borg 会自动填入你所连接的地址。如果你的计算机需要用另一个名称访问该服务器（例如 SSH 别名，或通过跳板机访问），请改为输入该名称。SSH 必须能够免密码登录，即使用密钥或 SSH agent。`borg mcp setup prod` 会在命令行中输出同样的 Claude Code 和 Claude Desktop 配置方法。

### 智能体能做什么

连接后，智能体看到的和你一样：以文本形式呈现的屏幕本身、你当前处于面板还是控制台、两个面板、高亮和已标记的文件、命令行在哪里运行以及其中输入了什么。它用“位置”来指代各个地方：borg 所在机器上的绝对路径或 `~/…`、容器内的 `docker://web/etc/nginx`，或相对于当前面板的路径。无需询问，它就可以读取文件夹和文件（可按行范围读取，或只读取包含特定文本的行），查看最繁忙的进程和容器，以及在你的另一个面板中显示某个文件或文件夹。

任何会更改机器的操作，都会在一个对话框中等待你确认，对话框会完整展示更改内容：要运行的命令及其运行位置、新建的文件，或以 diff 形式呈现的编辑。内容较长时，可用方向键、PgUp 和 PgDn 或鼠标滚轮滚动，按 F3 可全屏查看对话框。在你选择“是”之前，默认选中的始终是“否”；如果在你决定期间文件发生了变化，编辑会被拒绝。对于已配对的计算机，`approval_mode` 会在为该会话开启“全部批准”之前先询问你一次。开启期间会一直显示一个标记；点击它或按 Ctrl+Alt+A 可立即关闭。该配对连接断开时，它也会自动关闭。配对时的批准与此相互独立。

命令会输入到一个你可以看到的 Shell 中，并且不会记入其历史。针对本机的命令会进入 borg 自己的控制台，命令运行期间控制台会显示出来，以便你回应 sudo 之类的提示；针对容器的命令则会进入 Docker 视图中该容器的 Shell。Shell 会在命令之间保留当前文件夹和变量。

智能体还可以替你输入文本供你检查：在提示符处输入一条命令，或在控制台中打开的 vim 或 nano 里输入一段脚本。这些文本不会被执行：永远不会按下 Enter，多行文本会以粘贴的方式输入，Shell 和编辑器只会插入而不会运行它。

智能体还能以与内存搜索相同的方式搜索进程内存，查找字符串、指标、文本或字节。内存中可能保存着密码、密钥和私密消息，而搜索到的任何内容都会发送给智能体，因此对每个进程的首次搜索都需要你在对话框中批准，对话框会列出进程、其程序以及搜索内容。批准之后，在 borg 退出之前，智能体都可以再次搜索该进程。它可以请求以管理员身份读取，这会弹出系统自身的密码提示。

智能体连接后，快捷键栏开头会出现 **◈ 远程**。点击它可查看智能体的操作日志：它查看、读取、显示和输入了什么，以及每条命令和每项更改，无论被批准还是被拒绝。Borg 只在内存中保存日志，直到退出为止；如果完全不想保留日志，可在 选项 → 插件 中将其关闭。

### Borg cloud

借助 borg cloud，Claude 可以访问没有 SSH 路径可达的 borg：在浏览器终端中打开的服务器、容器，或位于 NAT 之后的机器。双方都主动向外连接到一个中继，由中继将它们连接起来。

1. 在服务器上的 borg 中按 F1 再按 C。第一个选项是带链接的 `borg pair`；按 Enter 即可复制。该链接只能使用一次，有效期十分钟。下方是中继：如果要使用其他中继，把它的地址粘贴到那里并按 Enter，即可保存该地址并获取经由它的链接。
2. 在你的计算机上的终端中运行该命令（你的计算机上也需要安装 borg）。它会输出一个配对码：六个 emoji，每个都附有名称，例如 `🐱 Cat · 🦁 Lion · 🐎 Horse`。
3. 服务器上的 borg 会询问是否配对，并显示你的计算机的名称和配对码。如果两边的配对码一致，选择“是”。随后，`borg pair` 会提议把该服务器添加到 Claude Code 中，即 `claude mcp add borg-NAME -- borg mcp remote NAME`。

配对码来自两个 borg 刚刚完成的加密握手，因此只有当与服务器通信的确实是你的计算机时，两边屏幕上的配对码才会一致。如果有人拿到了链接并抢先使用，服务器上显示的将是另一个配对码，而且对方无法让它与你的配对码相同。如果你的终端绘制的 emoji 比 borg 预期的窄，borg 只会显示名称；这时请比对名称。

此后，只要那台机器上的 borg 在运行，Claude 就能访问它。单独运行 `borg pair` 会列出已配对的服务器，`borg pair --forget NAME` 可忘记其中一个；在服务器上，在远程访问对话框中按 F8 会忘记所有已配对的计算机。通过 borg cloud，Claude 还能使用 `download` 和 `upload` 在服务器和你的计算机之间复制文件；在你的终端中，`borg get NAME:PATH [TO]` 和 `borg put FROM NAME:PATH` 可完成同样的操作。上传需要你在 borg 中批准，每次批准请求都会注明是哪台计算机发出的。

连接采用端到端加密。每个 borg 都在其状态文件夹中保存一个只有你能读取的私钥。配对时双方交换公钥，每次连接都以绑定这些公钥的 Noise IK 握手开始，因此中继转发的始终只是密文，也无法冒充任何一方的 borg 作出应答。来自另一台计算机的调用与本地调用一样，可以无需询问直接读取；在 选项 → 插件 中开启“另一台计算机读取前先询问”，可让这些读取同样需要批准。除非已经配对或正在显示配对链接，否则 borg 不会与中继保持连接；在 选项 → 插件 中关闭 borg cloud 后，则完全不会连接。

Borg 会将中继以 `relay = "wss://relay.example.com"` 的形式保存在配置中。计算机通过配对时所用的中继访问服务器，因此服务器更换中继后，需要重新配对计算机。同一台机器上的所有 borg 共用一个密钥，因此只有最先打开的那个会连接到中继；其他 borg 会告诉你是哪一个在使用 borg cloud。

### 命名会话与后台服务

使用命名工作区时，`borg sessions list` 显示它们的 ID 和名称，`borg sessions create NAME` 新建一个，`borg --session NAME` 打开它。通过 MCP，智能体可以调用 `list_sessions`、`list_remote_sessions` 和 `use_session` 来选择该连接所使用的会话。单次工具调用也可以传入 `session` ID，仅这一次针对另一个会话。所选会话只对该 MCP 连接有效。

`borg service install`、`enable` 和 `start` 用于设置可选的后台服务。该服务负责维持本机的配对连接，并在终端关闭后让命名会话继续运行。`borg service attach NAME` 可重新连接到某个会话，按 Ctrl-] 可再次分离，而不会结束其 Shell。使用 `borg service stop`、`disable` 或 `uninstall` 可停止或移除该服务。在没有 systemd 的容器中，请让容器的进程管理器运行 `borg service run`；`install` 和 `enable` 命令需要带有 systemd 的 Linux 主机。

### 远程面板

配对后，`borg --remote MACHINE:SESSION` 会在左侧面板中打开该会话的文件。按 Enter 或 F3 会下载一份临时的本地副本来预览远程文件。**F5** 可在本地面板和远程面板之间，或在两台已配对主机之间复制已标记的文件和文件夹，目标对话框会注明两侧分别是哪个客户端或主机。复制以后台任务的形式运行，显示字节进度，支持暂停和取消，遇到同名文件时可选择覆盖、跳过或保留两者。复制文件夹时会一并复制其中的空子文件夹和符号链接，普通文件会保留可执行权限和修改时间。文件只有在全部内容到达后才会出现在目标位置。远程面板中不提供 F6（移动）和 F8（删除）。

右侧面板始终显示你本机的内容。开启 **选项 → 插件 → 跟随** 后，命令行和 **Ctrl-O** 会使用远程主机上的交互式 Shell。其终端在本地绘制，而按键、粘贴的内容、Ctrl-C 和终端程序都在远程主机上运行。切换面板时，每个远程会话都会保留各自的 Shell 和未完成的命令行；选中客户端面板则会切回本地 Shell。

全屏程序以及 `top` 这类读取原始键盘输入的程序，在运行期间会接收所有按键（包括 Ctrl-O），调整终端大小也会同步调整远程 PTY 的大小。请使用程序自己的按键退出（例如按 `q` 退出 `top`）。如果程序是从面板命令行启动的，退出后 Borg 会返回面板；如果是在远程控制台中启动的，控制台会保持打开。远程 Borg 自身的面板和 Shell 与此控制台相互独立。要在命令行中传输文件，请使用 `borg get MACHINE/SESSION:PATH [TO]` 和 `borg put FROM MACHINE/SESSION:PATH`。

在 Borg 的主 Bash、Zsh 或 Fish Shell 中输入 `exit` 时会请求确认。默认选中 **否**，即保持同一个 Shell、变量、文件夹和镜像继续运行。在远程控制台中，`exit` 会询问是否关闭主机上的 Shell；选择“是”之后，可按 Alt-H 重新选择该会话，以获得一个新的 Shell。

远程文件夹分块加载，期间会显示加载动画和已接收的条目数；切换到其他文件夹会取消该请求。

### 远程主机

在本地 Borg 中，按 **Alt-H**、点击快捷键栏中的 **远程主机**，或选择 **F9 → 远程 → 浏览主机和会话**，即可查看已配对的机器及其命名会话。按 Enter 会在你打开选择器的那个面板中打开所选会话的文件，替换该面板原有的内容。按 **M** 镜像该会话的屏幕，按 **R** 刷新列表。

**Tab** 在 **主机**（本 Borg 能访问的计算机）和 **客户端**（能访问本 Borg 的计算机）之间切换。客户端列表显示与本 Borg 配对的计算机、它们的公钥指纹、是否已连接，以及各自的连接数。即使一个镜像使用了多个连接，同一台计算机也只列出一次。选择器打开期间状态会实时更新，包括连接由后台服务持有的会话。配对是单向的：被允许的客户端并不会自动成为本 Borg 可以浏览其文件的主机。如果连接的持有者无法报告连接状态，已配对的客户端仍会列出，并显示 **连接状态不可用**。同一个 Borg 可以同时是主机和客户端。“远程”菜单还提供 **镜像已挂载的主机** 和 **将此 Borg 共享为主机…**。

选择器会显示每台主机的 Borg 版本。选中某个会话后，会显示其操作系统和架构、是以后台服务还是在终端中运行、请求延迟以及中继地址。各主机会并行检查，因此一台主机不可用不会拖慢其他主机。无法报告版本的主机会显示 **版本不可用**；显示的版本始终是主机的版本，与中继无关。请在两台计算机上都保持 Borg 为最新版本：如果主机缺少某项远程功能，会显示提示信息，要求你升级。

镜像连接期间，选择器会显示动态状态，按 **Esc** 可立即取消。每个连接步骤限时 10 秒，整个连接尝试限时 30 秒。如果尝试失败，选择器会保持打开，并指出哪一步失败；按 **M** 可再次尝试连接所选会话。

在选择器中，**F2** 为所选主机重命名（作用于该主机上的所有会话），**Shift-F2** 为所选会话重命名。这些名称保存在当前客户端上，并显示在选择器、面板标题和控制台页脚中。将名称留空即可恢复原名。详细信息中仍会显示原始的主机名和会话名。名称与已配对主机的密钥和会话 ID 绑定；命令目标以及远程主机上的名称都不会改变。

在不可用的主机上按 **F8**，会在当前客户端上忘记其配对；按 **Shift-F8** 则即使所选主机在线也会将其忘记。确认对话框默认选中“否”。忘记主机会关闭当前客户端为该主机打开的面板和控制台；主机上的会话和文件都会保留，当前客户端的身份及其他配对也不受影响。重新配对即可再次连接。

在主机会话上按 **F8** 或 **Delete** 可将其移除，确认对话框默认选中 **否**。这会关闭该会话及其远程控制台，并删除其保存的 Borg 面板和终端历史；主机上的文件和文件夹会保留。默认会话无法移除。当前正在承载连接的独立会话不能移除自身；请先在主机上关闭它，并在另一个会话中运行 Borg。如果移除失败，该会话仍会保留在列表中，方便你重试。由服务管理的会话会先停止，再删除其保存的状态，服务也不会重新创建它们。

### 镜像会话

`borg mirror MACHINE:SESSION` 会在本地终端中显示远程会话的实时屏幕；在带有远程面板的本地 Borg 中，按 Alt+Shift+M 可打开同样的镜像。按 **Ctrl-G**（按住 Control 再按 G）可离开镜像并返回本地面板，点击底部的横幅也可以。横幅上方的一行显示当前由谁控制；按 Ctrl-] 也可以退出。

普通的 `borg` 或 `borg --session NAME` 在运行时即可被镜像，无需后台服务。它自己的终端仍然可见，在那里进行任何键盘或鼠标输入，都会从镜像手中收回控制权。镜像会沿用主机终端的布局，窗口较小时会截断显示；把窗口调大即可看到其余部分。可选的后台服务能让会话在原终端关闭后继续运行，并允许拥有控制权的客户端调整其 PTY 的大小。

如果另一个终端正控制着远程会话，镜像会以只读模式打开，你的按键不会传到该会话。按 **Ctrl-T** 或点击状态行可夺取控制权并断开另一个终端，也可以直接用 `borg mirror MACHINE:SESSION --take` 启动；`--take` 总会从其他查看者手中夺取控制权。获得控制权后，第一次按键会唤醒处于休眠状态的远程屏幕，之后的按键和鼠标输入都会传到该屏幕。跟不上进度的查看者会跳过过时的动画帧，直接显示当前屏幕。

### 运行中继

`borg-relay` 是各个 borg 相互连接所经由的中继。在一台有域名指向、且 443 端口空闲的 Linux 服务器上，一条命令就能将其安装为服务，并自动获取 Let's Encrypt 签发的 TLS 证书：

```sh
curl -fsSL https://raw.githubusercontent.com/0xcd21h/borg-commander/main/scripts/install-relay.sh | sudo sh -s -- relay.example.com you@example.com
```

再次运行同一条命令即可更新。

在 Dokploy、Coolify 或其他由代理处理 TLS 的 Docker 主机上，运行镜像 `ghcr.io/0xcd21h/borg-relay:latest`，并为其 8080 端口配置域名。在 Dokploy 中，基于该 Docker 镜像创建一个应用，为容器的 8080 端口配置域名并开启 HTTPS；在 Coolify 中，基于该 Docker 镜像创建一个资源，暴露 8080 端口并配置域名。两者也都可以将 [packaging/relay/docker-compose.yml](../../../packaging/relay/docker-compose.yml) 作为 Compose 服务使用。该镜像运行 `borg-relay --behind-proxy`：由代理提供 HTTPS 并透传 WebSocket，中继则按代理在 `X-Forwarded-For` 中报告的客户端地址实施各项限制。它以非特权用户身份运行，并带有健康检查（`GET /health`）。

在没有此类代理的 Docker 主机上，同一个镜像可以自行提供 TLS：

```sh
docker run -d --restart unless-stopped -p 443:443 -v borg-relay:/data ghcr.io/0xcd21h/borg-relay --domain relay.example.com --cache /data
```

如果位于其他处理 TLS 的代理之后，请运行 `borg-relay --behind-proxy --listen 127.0.0.1:8080`。只有在代理之后才能这样运行，因为中继会信任代理报告的客户端地址。中继会按地址限制服务器和会话的数量、帧大小、带宽、每个会话的字节数、空闲时间和会话时长。除了证书之外，它不存储任何内容。

中继的日志只记录计数：如果有变化，每分钟写入一行，例如：

```text
stats: connections=3 servers=2 sessions=1 joined=14 carried=3.2MiB limited=0
```

这一行显示它当前持有的连接数、已注册的服务器数和已打开的会话数，以及自启动以来加入的会话数、这些会话传输的字节数，以及因触发限制而被拒绝或终止的连接和会话数。调试时，使用 `--log`（对于镜像则设置环境变量 `BORG_RELAY_LOG=1`），还会记录每台服务器的注册情况（以其密钥的开头部分标识）、每个会话及其传输的字节数，以及每次触发限制时的客户端地址。

## 查找、任务与查看器

Ctrl-S 打开快速查找。输入名称或 `*.rs` 之类的 glob；Down 和 Up 在匹配项之间移动，Insert 标记匹配项，Ctrl-A 标记所有匹配项，Enter 或 Esc 关闭搜索。除非查询中包含大写字母，否则匹配不区分大小写。

### 复制、移动与删除

F5、F6 和 F8 分别启动复制、移动和删除任务。Alt-J 打开任务列表，可在其中暂停或取消任务。

“复制”对话框中有一个 **针对机械硬盘优化复制** 复选框。按 Tab 移到该复选框，按 Space 切换，也可以直接点击。每次新建复制时它都处于未勾选状态。在此模式下，Borg 会把小文件分批读入内存，再逐批写出，在同一块机械硬盘内复制时可以减少磁盘寻道。每批最多包含 64 MiB 文件数据或 4,096 个文件；大于 1 MiB 的文件按常规方式复制。效果取决于硬盘、文件系统和操作系统缓存，在不同硬盘之间复制时可能反而更慢。目标位置已存在同名文件时：`o` 覆盖，`s` 跳过，`k` 保留两者，`a` 全部覆盖，`n` 全部跳过，Esc 取消。复制的内容会先写入临时文件，完成后再重命名。

### 查看器与快速预览

F3 打开查看器。查看文本文件时，方向键和 PgUp/PgDn 用于滚动，`w` 开启或关闭自动换行，Esc 或 `q` 关闭查看器。查看图片时，Left/Right 或 `p`/`n` 切换到上一张或下一张图片。如果终端支持图像协议，Borg 会使用它；其他终端则以彩色色块显示图像。

Ctrl-Q 在另一个面板中显示快速预览。按 Tab 进入预览，可用方向键、PgUp/PgDn、Home/End 和鼠标滚轮滚动；按 Tab 或 Esc 返回文件列表。Ctrl-L 显示文件信息。F3 会在完整查看器中打开文本预览，关闭查看器后会回到预览，并保留滚动位置、换行设置和源码模式。两者读取文件的方式同样有所限制，因此打开大型文本文件时只读取第一页左右的内容，无论文件多大都能很快打开。对于按文本搜索得到的结果，预览会改为在文件的第一处匹配处打开，像查找栏那样标出查询，并且只读取这处匹配附近的内容。

两种文本查看器都会对常见的编程语言、标记语言和配置文件进行语法高亮，包括 Rust、Python、JavaScript、TypeScript/TSX、Go、C/C++、Java、C#、Ruby、PHP、Lua、SQL、HTML/CSS、JSON、YAML、TOML、Shell 脚本和 Dockerfile。Markdown 默认以渲染后的格式打开；在任一查看器中按 `s` 或 F4 可切换到源码。支持标题、强调、列表、任务列表、链接、表格和围栏代码块。大于 2 MiB 的 Markdown 文件会以源码形式打开，以减少内存占用。

JSON 文件会以每行一个值的方式排版打开，键保持原有顺序，数字保持原样，这对写在一行里的文件最有帮助。按 `s` 或 F4 可查看文件原样。JSON Lines 文件（`.jsonl`、`.ndjson`）会逐条记录排版。大于 16 MiB 或无法解析的 JSON 会按原样打开。

### 编辑器

F4 在 Borg 的编辑器中打开所选文件，Shift-F4 则在 `$VISUAL` 或 `$EDITOR` 中打开。编辑器会保留文件原有的换行符和缩进，像查看器一样高亮代码，并显示行号。按住 Shift 加方向键可选择文本；Ctrl-C、Ctrl-X 和 Ctrl-V 通过 Borg 的剪贴板进行复制、剪切和粘贴，从终端粘贴的文本会原样插入。Ctrl-Z 和 Ctrl-Y 撤销和重做，Tab 和 Shift-Tab 增加和减少缩进。F2 或 Ctrl-S 会通过临时文件保存，因此文件永远不会只写了一半。非 UTF-8 文本文件或大于 32 MiB 的文件会改为在查看器中打开。超过 20,000 个字符的行（例如压缩过的代码）不做语法高亮，而且只绘制一行中显示在屏幕上的部分，因此即使是写在一行里的大文件，编辑起来也没有延迟。Alt-Shift-F 会按文件自身的缩进把 JSON 文件排版为每行一个值，这一步可以用 Ctrl-Z 撤销；无法解析的 JSON 会保持不变，状态行会说明解析在哪里停止。

编辑器会在文本上方弹出对话框进行询问：Tab 在字段和按钮之间移动，Enter 确认当前选中项，Esc 取消，也可以直接点击。Ctrl-F 或 F7 使用下文介绍的查找栏查找文本。Ctrl-R 或 F4 进行替换，可使用与查找栏相同的开关：Enter 替换当前匹配项并跳到下一个，**跳过** 保留当前匹配项，Alt-A 或 **全部** 一次性替换所有匹配项，且只需一次 Ctrl-Z 即可撤销。使用正则表达式时，替换内容中的 `$1` 会放回第一个分组匹配到的文本。Ctrl-G 跳转到指定行。Esc 关闭编辑器，如有未保存的更改，会先询问保存还是放弃；如果自打开以来文件在磁盘上发生了变化，Borg 会询问是覆盖还是重新加载。单击可放置光标，拖动或按住 Shift 单击可选择文本，双击选中一个单词，滚轮用于滚动；状态行中显示的按键也可以点击。

Alt-E 在当前面板内用 Borg 的编辑器打开所选文件，取代该面板的文件列表，这样就可以并排编辑两个文件，或者在文件所在的文件夹旁边编辑它。在搜索结果和集合中，Alt-E 会在另一个面板中打开编辑器，让列表保持可见。在另一个结果上按 Alt-E，会用它替换那里的文件；如果那个文件有未保存的更改，Alt-E 会把它的编辑器调到前面，并询问是否保存。F6 从面板中的编辑器切换到另一面板，在文件列表中按 Tab 则回到编辑器。在一个编辑器中用 Ctrl-C 复制的文本，可以在另一个编辑器中用 Ctrl-V 粘贴。编辑器获得焦点时，快捷键栏显示编辑器的按键，回到文件列表后恢复面板的按键。在编辑器中按 Ctrl-O 同样会显示控制台，F9 打开菜单。Esc 或 F10 关闭编辑器，面板重新显示文件；退出时会先逐一询问有未保存更改的面板编辑器。快速预览和文件信息需要用到另一面板，因此要等那里的编辑器关闭后才能使用。在结果旁打开的编辑器关闭时，会把焦点交还给结果，并恢复它们之前显示的快速预览或文件信息。

查看器和编辑器查找文本的方式相同。在查看器中，按 `/`、F7 或 Ctrl-F 会在状态行中打开查找栏；在编辑器中则按 Ctrl-F 或 F7。Borg 会从查找栏打开的位置开始边输入边搜索：屏幕上的每个匹配项都会被标出，当前匹配项会突出显示，查找栏会显示计数（第 3 个，共 17 个）。Enter、Down 或 F3 跳到下一个匹配项，Shift-Enter、Up 或 Shift-F3 跳到上一个；越过最后一个匹配项后，搜索会从另一端继续并给出提示。Alt-C 精确匹配大小写（否则全小写的查询不区分大小写），Alt-W 匹配整个单词，Alt-R 把查询当作正则表达式；这些开关也可以点击。Ctrl-P 和 Ctrl-N 调出最近的查询。Esc 关闭查找栏；之后在查看器中按 `n` 和 `N`，或在编辑器中按 F3 和 Shift-F3，可以继续在匹配项之间跳转。在大文件中，查看器会在后台搜索并显示进度，按 Esc 即可停止。对于不超过 64 MiB 的文件，它会统计匹配项，最多 10,000 个。

## 配置

在 **F9 → 选项 → 语言** 中更改界面语言。选择英语、简体中文、葡萄牙语（葡萄牙）、西班牙语或俄语，然后按 Enter；按 Esc 取消。所选语言会保存在 `config.toml` 中，即 `language = "en"`、`"zh-CN"`、`"pt"`、`"es"` 或 `"ru"`。`BORG_LANGUAGE` 会覆盖已保存的设置。如果两者都未设置，Borg 会遵循 `LC_ALL`、`LC_MESSAGES` 或 `LANG`，遇到不支持的语言则使用英语。命令、路径、文件名和键盘快捷键永远不会被翻译。本网站上的语言菜单只切换本指南的语言，与应用界面语言相互独立。

设置保存在 `~/.config/borg-commander/config.toml` 中，或保存在由 `$XDG_CONFIG_HOME` 或 `$BORG_CONFIG_DIR` 指定的文件夹中。F9 → 选项 → 设置 以复选框的形式列出这些设置；按 Space 或单击可切换某项设置并立即保存。按 Esc 关闭窗口。

```toml
theme = "neon"              # midnight, aurora, neon, classic, paper, ember, or your own
icon-style = "auto"         # auto, nerd, or portable; Ghostty gets rich icons automatically
icon-spacing = 1            # spaces after an icon, 1 to 3
status-line = true
menu-bar = false            # keep the menu bar visible
show-hidden = false
return-to-panels = true    # return after commands launched from the panels
restore-terminal = false    # bring back the shell scrollback on the next start
screensaver = true          # a spinning cube or a glitching logo, picked at random
screensaver-after = 300     # seconds of idle time
```

## 活动与内存

按 **Alt-M** 或选择 **命令 → 进程监视器** 打开进程监视器。它由内置的“系统”插件提供，该插件默认启用，可在 选项 → 插件 中关闭。进程列表占据当前窗格，另一个窗格显示所选进程的内存概览。按 **Enter** 或双击，会在监视器上方的窗口中打开该进程，一侧是内存映射，另一侧是所选内存区域的字节预览。**Esc** 关闭该窗口，**Tab** 在两侧之间切换。**Alt-W** 或 **[+]** 按钮最大化当前焦点所在的窗格，**[=]** 恢复分栏，**[-]** 隐藏监视器。监视器打开期间每秒采样一次，关闭后即停止采样。进行内存检查时采样会暂停，结果返回后再恢复。

列表显示 CPU、驻留内存、内存增长以及磁盘读写速率。CPU 100% 表示一个核心满负荷运行。多个进程共享的驻留页面会分别计入每个进程，因此把所有进程的 RAM 加起来并不等于系统总量。CPU 和磁盘速率从第二次采样开始显示。

| 按键 | 操作 |
| --- | --- |
| Enter | 打开进程的内存映射 / 移到内存区域预览 |
| `/` | 按名称或 PID 筛选；↑↓ 仍可移动，Enter 保留筛选条件，Esc 清除筛选条件 |
| C / M / G / N / P | 按 CPU / RAM / 增长 / 名称 / PID 排序；再按一次则反向排序 |
| I / O | 按读取 / 写入速率排序 |
| T | 显示或隐藏进程树 |
| K | 发送信号或更改优先级 |
| Space | 暂停或恢复采样 |
| R | 刷新当前视图 |
| Esc | 返回；在进程列表中则关闭监视器 |

单击列标题可排序，双击进程可打开其内存映射。概览显示当前驻留内存、观测到的最高值、自开始监视以来的变化、CPU、虚拟地址空间，以及最近 60 秒驻留内存的图表。读取内存映射后，如果系统提供相应数据，还会显示内存占用、交换、私有和共享的总量。在内存窗格中按 **Enter** 可打开内存映射。内存映射只在你请求时读取；进程更改其映射后，按 R 可重新读取。

### 信号和优先级

按 K 可为所选进程打开 **信号或优先级**。按某个选项的字母，或移到该选项后按 Enter。Esc 关闭对话框，不发送任何内容。

| 按键 | 选项 | 作用 |
| --- | --- | --- |
| T | **终止** | 发送 TERM，请求进程退出 |
| I | **中断** | 发送 INT，与在其终端中按 Ctrl-C 相同 |
| H | **挂断** | 发送 HUP；许多服务会重新读取设置 |
| K | **强制结束** | 发送 KILL，立即结束进程，不给它清理的机会 |
| S | **暂停** | 发送 STOP，让进程暂停 |
| C | **继续** | 发送 CONT，让已暂停的进程继续运行 |
| L | **降低优先级** | 将其 nice 值提高 5，最高到 19，系统繁忙时它会更晚获得 CPU |
| R | **提高优先级** | 将其 nice 值降低 5，最低到 -20 |

发送之前，Borg 会确认该 PID 仍属于你选择的进程，且启动时间相同，因此复用该 PID 的新进程不会受到影响。状态行会确认发送了什么，列表也会立即重新采样。进程暂停时，概览会注明这一点；nice 值不为 0 时，概览会显示其 **Nice 值**。

你可以向自己的进程发送信号，也可以降低它们的优先级。其余操作会被系统拒绝：其他用户的进程，以及只有管理员才能执行的提高优先级。此时 Borg 会提供 **A 管理员**，通过[管理员权限](#administrator-access)中介绍的辅助程序发送同一选项。Borg 不会向自身发送信号；按 F10 可退出它。

### 内存映射

内存映射有三列：

- **内存占用**：仅计入该进程自身的内存，即它写入过的页面，加上被换出或被压缩的页面。排查内存泄漏时应关注这个数值；在 macOS 上，它与“活动监视器”中的 *内存* 列一致。
- **驻留**：当前位于 RAM 中的页面，包括与其他进程共享的页面。
- **映射**：地址空间，包括预留的部分。它与 RAM 用量无关。

一个进程可能映射了数 GB 的空间（大多是与其他所有进程共享的系统库），而它的内存占用只有几 MB。内存区域起初按用途分组：堆与动态分配、线程栈、程序代码和数据、共享库、映射文件、共享内存、系统及其他分配，以及保留区与保护页。各组及组内的内存区域按内存占用排序，预留部分排在最后。库和映射文件每个文件占一行；展开文件即可查看其内存区域。组名是根据操作系统提供的标签推断出来的。选中某个组或文件时，会说明它是什么，并显示它在内存占用中所占的份额及其中最大的成员。Enter 或 Right 展开组或文件；Left 将其折叠，或折叠包含所选行的那一项。G 在分组视图和原始列表之间切换。

### 打开的文件

**1 内存** 和 **2 打开的文件** 用于在检查标签页之间切换，也可以直接点击。打开的文件列表会显示每个描述符及其访问模式、类型，以及路径或网络端点；另一个窗格会在可获取时显示完整详细信息、文件大小和当前偏移量。在 macOS 上，列表还包括 `cwd`（当前目录）和 `txt`（映射的可执行文件）等条目。R 刷新列表。切换标签页时，每个标签页都会保留各自在列表中的位置。访问受限时，Borg 会提议以管理员身份重试。对于普通文件，详细信息中还会像快速预览一样预览其内容：按 **Tab** 进入预览即可滚动，按 **F3** 在查看器中打开该文件。Borg 以你自己的权限按路径打开文件，不会动用该进程的描述符。

### 内存区域预览

选中一个可读的内存区域时，Borg 会在另一个窗格中捕获该区域最多 64 KiB 的内容。如果区域开头全是零，捕获会跳到第一个含有数据的页面，字节上方的一行会说明窗口位于区域中的哪个位置。快速移动时，Borg 会稍等片刻再读取；选中另一个区域会清除旧的预览，并取消其尚未完成的读取。无法读取的区域会改为显示一条消息。按 **Tab** 或 **Enter** 可滚动预览。在预览中按 **Esc** 返回列表，在内存映射中按 **Esc** 则返回进程列表，光标和筛选条件保持原样。

连续的全零行会折叠成一行，例如“· 60K 个零字节 ·”。**]** 和 **[** 跳到下一个和上一个数据块，**>** 和 **<** 捕获该区域中下一个和上一个 64 KiB。**H** 在十六进制和文本之间切换，**R** 重新捕获当前显示的窗口，**D** 高亮显示与同一进程、同一地址上一次捕获相比发生变化的内容。文本视图显示可打印的 ASCII 字符，其他字节以点号代替。捕获是在不暂停进程的情况下从运行中的进程获取的，因此一次捕获无法保证与整个进程保持一致。除非导出，否则捕获只保存在内存中。**E** 会将原始字节保存为当前文件面板所在文件夹中的新文件，只有你能读取。绝不会覆盖已有文件。

**M** 在字节视图和该区域的页面图之间切换预览：每个 4 KiB 页面对应一个单元格（大区域中则是每组连续页面对应一个单元格），并按内容类型标注：指向进程自身内存的指针、文本、UTF-16 文本、代码、压缩或加密数据、其他数据、填充、零，以及不在内存中的页面。图例显示每种类型在该区域中所占的比例。页面图获得焦点时，方向键、**PgUp**、**PgDn**、**Home** 和 **End** 可移动光标，**Enter** 以字节形式打开光标所在的页面。超过 16,384 个页面的区域会均匀采样。在 Linux 上，页面图会向系统查询哪些页面在内存中，不读取其余页面，因此既不会把已换出的页面换回，也不会触碰新页面；在 macOS 上，从未被访问过的页面读出来都是零。类型仅根据字节内容推测，请将其视为提示。

### 内存搜索

在内存窗格中按 **/**，或在任一窗格中按 **Ctrl-F**，即可搜索内存。可以选择搜索模式、是否区分大小写，以及搜索进程的可读内存还是当前捕获。**文本** 搜索 UTF-8、UTF-16（两种字节序）和 UTF-32（两种字节序）。**Unicode** 还会对兼容字符和组合序列进行规范化：例如，`𝐁𝐨𝐫𝐠` 可以匹配 `Borg`。但它不会仅仅因为字母外形相似就将其视为相同。**十六进制** 接受 `42 6F 72 67` 这样的字节对。

**字符串** 和 **指标** 只读取进程自己填充的内存，即没有文件支撑、且进程可能写入的内存；在 macOS 上，还会跳过进程从未写入过的区域。**字符串** 会把每段至少六个可打印 ASCII 或 UTF-16LE 字符的连续字符串列出一次，并注明它在内存中的副本数，同时跳过重复字符或标点之类的填充内容；如果输入了查询，则只保留包含该查询的字符串。**指标** 会保留看起来像 URL、IP 地址、电子邮件地址、文件路径、命令行、机密信息（私钥、访问令牌或密码赋值）或长段 base64 的字符串，并为每一项加上标签。

Borg 还会读取进程所映射文件中的字符串（最多 1 GiB），并用 • 标出只在内存中找到的字符串：即进程自己构建、接收或解码、且不在其任何文件中的文本。排序时，指标排在最前，其次是只在内存中找到的字符串，然后是文件中也存在的字符串；看起来像单词的字符串排在其他字符串之前。列表最多保留最相关的 2,000 条。其他匹配项显示的是所在区域，而这里每行显示类型和副本数，预览中会显示该字符串所在的位置；按 **C** 可逐一查看其副本。请把这些结果当作值得进一步查看的线索。普通程序中本来也有大量 URL、路径和密钥。

匹配项会占据列表窗格，并显示其地址、编码和所在区域。选中匹配项后，另一个窗格会预览其周围的字节，并高亮显示匹配内容。Enter 进入预览，Esc 返回匹配列表。在匹配列表中按 Esc 会回到你之前所在的内存映射或进程列表。搜索已保存的捕获时，使用的是捕获中的字节，不会读取正在运行的进程。搜索进程时，会分块读取内存，报告无法读取的字节，并在找到 2,000 个匹配项或达到 60 秒后停止。**N** 从搜索停止处继续，**Ctrl-C** 停止搜索并保留结果。覆盖范围报告会区分已搜索的字节和无法读取的字节。进程在被搜索期间可能会更改其内存。

### 代码完整性检查

在内存映射或搜索匹配项中按 **I**，可检查进程运行的是否是其文件中的代码。它会将内存中的代码与其映射来源的文件进行比较，报告不一致的页面；在没有文件支撑的内存中搜索可执行映像（ELF、Mach-O 和 PE）的文件头；并列出没有文件支撑的可执行内存、同时可写又可执行的内存，以及来自已删除、无名称或临时文件的代码。它还会从整体上检查进程：通过 `LD_PRELOAD`、`LD_AUDIT`、`DYLD_INSERT_LIBRARIES` 或 `/etc/ld.so.preload` 注入的库、库搜索路径、Linux 上的跟踪器（tracer）、文件已被删除或替换的程序，以及与其程序名称不一致的进程名。

检查结果会占据列表窗格，按警报、警告、提示的顺序排列。选中一项后会预览其相关的字节并高亮显示证据，列表下方的几行会说明还有哪些其他可能的解释。在运行时编译代码的程序（例如浏览器以及 Java 和 JavaScript 引擎）总是会持有没有文件支撑的代码，因此对它们来说，这类结果只会作为提示。**R** 重新检查，**Ctrl-C** 停止检查并保留已有结果，**Esc** 返回。一次检查最多读取 512 MiB 代码和 1 GiB 其他内存，耗时不超过 45 秒；如果提前停止，会予以说明。

在 Linux 上，页表会显示进程修改过哪些代码页，因此只读取这些页面；在 macOS 上，同样不会读取没有修改页面的区域。macOS 共享缓存中的代码没有单独的文件，因此不做比较。检查无法读取的内存会被计数，Borg 会提供 **A 管理员** 选项。请把检查结果当作线索，因为调试器、性能分析器、更新程序和安全工具都会留下同样的痕迹。

### 管理员权限

当读取内存映射或捕获受到限制、搜索无法读取部分内存，或者系统拒绝信号或优先级更改时，Borg 会提供 **A 管理员** 选项。在 macOS 上，这会打开系统的授权提示；在 Linux 上，它使用 `pkexec`，并且需要有授权代理正在运行。只有一个短时运行的辅助程序会以提升的权限运行。Borg 本身仍以普通权限运行，辅助程序只返回映射数据或有限数量的字节，或者发送你选择的那一个信号或优先级。

macOS 会保护其自身程序（系统完整性保护，System Integrity Protection）以及使用强化运行时（Hardened Runtime）构建的程序的内存，使其他任何程序（包括管理员）都无法访问。Borg 会从程序的签名中读取这一信息：进程详细信息中会显示 **内存受保护**，被拒绝的读取会说明原因，而且不会提供 **A 管理员**，因为它也无济于事。这些程序的内存映射和打开的文件仍会显示。如果 Borg 已经以管理员身份运行，也不会提供该选项。在 Linux 上，安全策略仍可能拒绝访问；Borg 会显示错误，进程监视器则照常工作。

进程由其 PID 与启动时间共同标识，因此复用某个 PID 的新进程不会继承另一个进程的历史。内存映射、检查结果、捕获和历史都有大小限制。Borg Commander 的名称始终显示在右下角，包括控制台、查看器、监视器、对话框和屏保中。
