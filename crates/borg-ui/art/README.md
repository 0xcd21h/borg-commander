# Art

`stewart.pgm` is the portrait Borg shows in empty folders on October 28, the day Sir Patrick
Stewart died in 2026. It is a grayscale image cropped, masked, contrast-adjusted and scaled
from [Patrick Stewart by Gage Skidmore 2.jpg](https://commons.wikimedia.org/wiki/File:Patrick_Stewart_by_Gage_Skidmore_2.jpg)
by Gage Skidmore, licensed under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).
This derived image is shared under the same license, not under Borg's MIT or Apache license.
